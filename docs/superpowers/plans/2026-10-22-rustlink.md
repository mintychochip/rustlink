# rustlink Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `rustlink`, a Rust library of narrow typed links (1, 2, 4 and 8 byte offsets that replace pointers) with an append-only arena and a verified, position-independent blob, plus a benchmark suite that measures where narrow links pay and gates a future byte-addressed layer.

**Architecture:** A `#![no_std]` library crate `rustlink` (links, regions, arena, blob) with no hand-written `unsafe`, and a workspace crate `rustlink-bench` (one runner process per benchmark cell, a sweep driver, a Markdown report). Every link resolution is bounds-checked against a `Region`; offsets count elements and are resolved through `(region, owner index, link)`. The work runs in waves: a sequential foundation (Wave 0), three independent benchmark slices (Wave 1), then integration, review, the sweep and docs (Wave 2).

**Tech Stack:** Rust stable features (edition 2024, `rust-version = "1.88"`), `zerocopy` 0.8, `proptest` 1 (dev only). Benchmarks use `/proc`, `taskset` and the standard library only.

**Spec:** `docs/superpowers/specs/2026-10-22-rustlink-design.md` (read it first; this plan implements it and notes where the verified implementation refined it).

## Global Constraints

Every task's requirements implicitly include this section. Values are copied from the spec.

````rust
/// A BST node whose child links can be set generically.
pub trait BstNode: Copy {
    type Child: Link<Self>;
    fn leaf(key: u32) -> Self;
    fn key(&self) -> u32;
    fn left(&self) -> Self::Child;
    fn right(&self) -> Self::Child;
    fn set_left(&mut self, owner: usize, target: usize) -> Result<(), LinkError>;
    fn set_right(&mut self, owner: usize, target: usize) -> Result<(), LinkError>;
}

macro_rules! bst_node {
    ($name:ident, $link:ident, $w:ty, $schema:expr, |$owner:ident, $target:ident| $make:expr) => {
        #[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned, Clone, Copy)]
        #[repr(C)]
        pub struct $name {
            pub key: U32,
            pub left: $link<$name, $w>,
            pub right: $link<$name, $w>,
        }

        impl_links!($name, schema = $schema, links = [left, right]);

        impl BstNode for $name {
            type Child = $link<$name, $w>;

            fn leaf(key: u32) -> Self {
                Self {
                    key: U32::new(key),
                    left: $link::NULL,
                    right: $link::NULL,
                }
            }
            fn key(&self) -> u32 {
                self.key.get()
            }
            fn left(&self) -> Self::Child {
                self.left
            }
            fn right(&self) -> Self::Child {
                self.right
            }
            fn set_left(&mut self, $owner: usize, $target: usize) -> Result<(), LinkError> {
                self.left = $make?;
                Ok(())
            }
            fn set_right(&mut self, $owner: usize, $target: usize) -> Result<(), LinkError> {
                self.right = $make?;
                Ok(())
            }
        }
    };
}

/// Inserts `key` into the BST stored in `arena` (root at index 0). Duplicates are ignored.
pub fn arena_insert<N: BstNode>(arena: &mut Arena<N>, key: u32) -> Result<(), LinkError> {
    if arena.is_empty() {
        arena.push(N::leaf(key));
        return Ok(());
    }
    let mut at = 0usize;
    loop {
        let (node_key, child) = {
            let node = &arena.as_slice()[at];
            (
                node.key(),
                if key < node.key() {
                    node.left()
                } else {
                    node.right()
                },
            )
        };
        if key == node_key {
            return Ok(());
        }
        match arena.follow(at, child) {
            Some((next, _)) => at = next,
            None => {
                let new = arena.push(N::leaf(key));
                let node = arena.get_mut(at).expect("owner exists");
                return if key < node_key {
                    node.set_left(at, new)
                } else {
                    node.set_right(at, new)
                };
            }
        }
    }
}

/// True if the BST rooted at index 0 of `region` contains `key`.
pub fn region_contains<N: BstNode, R: Region<N>>(region: &R, key: u32) -> bool {
    let Some(mut cursor) = region.cursor(0) else {
        return false;
    };
    loop {
        let node = cursor.get();
        if key == node.key() {
            return true;
        }
        let child = if key < node.key() {
            node.left()
        } else {
            node.right()
        };
        match cursor.follow(child) {
            Some(next) => cursor = next,
            None => return false,
        }
    }
}

/// Keys of the BST rooted at index 0 of `region`, in order.
pub fn in_order<N: BstNode, R: Region<N>>(region: &R) -> Vec<u32> {
    fn walk<N: BstNode>(cursor: Cursor<'_, N>, out: &mut Vec<u32>) {
        let node = cursor.get();
        if let Some(left) = cursor.follow(node.left()) {
            walk(left, out);
        }
        out.push(node.key());
        if let Some(right) = cursor.follow(node.right()) {
            walk(right, out);
        }
    }
    let mut out = Vec::new();
    if let Some(root) = region.cursor(0) {
        walk(root, &mut out);
    }
    out
}

/// A BST of exactly `n` distinct keys (n < 1009) inserted in a scrambled order.
pub fn build_tree<N: BstNode>(n: usize) -> Arena<N> {
    let mut arena = Arena::new();
    for i in 0..n {
        arena_insert(&mut arena, ((i * 7919) % 1009) as u32).expect("links fit");
    }
    arena
}

/// Boxed reference BST used as the oracle in differential tests.
#[derive(Default)]
pub struct BoxBst {
    root: Option<Box<BoxNode>>,
}

struct BoxNode {
    key: u32,
    left: Option<Box<BoxNode>>,
    right: Option<Box<BoxNode>>,
}

impl BoxBst {
    pub fn insert(&mut self, key: u32) {
        let mut slot = &mut self.root;
        while let Some(node) = slot {
            slot = match key.cmp(&node.key) {
                core::cmp::Ordering::Less => &mut node.left,
                core::cmp::Ordering::Greater => &mut node.right,
                core::cmp::Ordering::Equal => return,
            };
        }
        *slot = Some(Box::new(BoxNode {
            key,
            left: None,
            right: None,
        }));
    }

    pub fn contains(&self, key: u32) -> bool {
        let mut slot = &self.root;
        while let Some(node) = slot {
            match key.cmp(&node.key) {
                core::cmp::Ordering::Equal => return true,
                core::cmp::Ordering::Less => slot = &node.left,
                core::cmp::Ordering::Greater => slot = &node.right,
            }
        }
        false
    }
}
````

````rust
/// Indices around the edges of width `W`.
fn edge_indices<W: Width>() -> Vec<usize> {
    let max = W::MAX;
    [0, 1, max.saturating_sub(1), max, max.saturating_add(1)]
        .into_iter()
        .filter_map(|v| usize::try_from(v).ok())
        .collect()
}

fn check_abs<W: Width>() {
    for index in edge_indices::<W>() {
        match Abs::<(), W>::new(index) {
            Ok(link) => {
                assert!(index as u64 <= W::MAX);
                assert_eq!(link.index(), index);
                assert_eq!(link.target(7), Target::Index(index));
            }
            Err(LinkError::OutOfRange { value, min, max }) => {
                assert!(index as u64 > W::MAX);
                assert_eq!((value, min, max), (index as i128, 0, i128::from(W::MAX)));
            }
            Err(other) => panic!("unexpected error {other:?}"),
        }
    }
}

fn check_opt_abs<W: Width>() {
    assert_eq!(OptAbs::<(), W>::new(None).unwrap().get(), None);
    assert_eq!(OptAbs::<(), W>::NULL.get(), None);
    assert_eq!(OptAbs::<(), W>::default(), OptAbs::NULL);
    for index in edge_indices::<W>() {
        match OptAbs::<(), W>::new(Some(index)) {
            Ok(link) => {
                assert!((index as u64) < W::MAX);
                assert_eq!(link.get(), Some(index));
                assert_eq!(link.target(0), Target::Index(index));
            }
            Err(LinkError::OutOfRange { .. }) => assert!(index as u64 >= W::MAX),
            Err(other) => panic!("unexpected error {other:?}"),
        }
    }
    assert_eq!(OptAbs::<(), W>::NULL.target(0), Target::Null);
}

fn check_rel<W: Width>(owner: usize, target: usize) {
    let delta = target as i128 - owner as i128;
    let fits = delta >= i128::from(W::SIGNED_MIN) && delta <= i128::from(W::SIGNED_MAX);
    match Rel::<(), W>::new(owner, target) {
        Ok(link) => {
            assert!(fits);
            assert_eq!(i128::from(link.delta()), delta);
            assert_eq!(link.target(owner), Target::Index(target));
        }
        Err(LinkError::OutOfRange { value, .. }) => {
            assert!(!fits);
            assert_eq!(value, delta);
        }
        Err(other) => panic!("unexpected error {other:?}"),
    }
}

fn check_opt_rel<W: Width>(owner: usize, target: usize) {
    if owner == target {
        assert_eq!(
            OptRel::<(), W>::new(owner, Some(target)),
            Err(LinkError::NullCollision)
        );
        return;
    }
    let delta = target as i128 - owner as i128;
    let fits = delta >= i128::from(W::SIGNED_MIN) && delta <= i128::from(W::SIGNED_MAX);
    match OptRel::<(), W>::new(owner, Some(target)) {
        Ok(link) => {
            assert!(fits);
            assert_eq!(link.delta().map(i128::from), Some(delta));
            assert_eq!(link.target(owner), Target::Index(target));
        }
        Err(LinkError::OutOfRange { .. }) => assert!(!fits),
        Err(other) => panic!("unexpected error {other:?}"),
    }
}
````

````rust
//! Storage widths for links.

use zerocopy::byteorder::little_endian::{U16, U32, U64};
use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};

mod sealed {
    pub trait Sealed {}
}

/// Unsigned width of a stored link offset.
///
/// Sealed: implemented for `u8`, `u16`, `u32` and `u64` only.
pub trait Width: sealed::Sealed + Copy + 'static {
    /// Storage size in bytes.
    const BYTES: usize;
    /// Largest unsigned value, `2^(8 * BYTES) - 1`.
    const MAX: u64;
    /// Smallest signed value, `-2^(8 * BYTES - 1)`.
    const SIGNED_MIN: i64;
    /// Largest signed value, `2^(8 * BYTES - 1) - 1`.
    const SIGNED_MAX: i64;
    /// The all-zero storage value.
    const ZERO: Self::Le;
    /// Alignment-1 little-endian storage for one offset.
    type Le: Copy
        + Eq
        + core::hash::Hash
        + core::fmt::Debug
        + FromBytes
        + IntoBytes
        + Immutable
        + KnownLayout
        + Unaligned;
    /// Encodes the low `BYTES` bytes of `raw`. The caller guarantees `raw <= MAX`.
    fn encode(raw: u64) -> Self::Le;
    /// Decodes the stored value as an unsigned integer.
    fn decode(le: Self::Le) -> u64;
    /// Encodes `v` as two's complement. The caller guarantees `SIGNED_MIN <= v <= SIGNED_MAX`.
    fn encode_signed(v: i64) -> Self::Le;
    /// Decodes the stored value as a sign-extended two's-complement integer.
    fn decode_signed(le: Self::Le) -> i64;
}

impl sealed::Sealed for u8 {}

impl Width for u8 {
    const BYTES: usize = 1;
    const MAX: u64 = u8::MAX as u64;
    const SIGNED_MIN: i64 = i8::MIN as i64;
    const SIGNED_MAX: i64 = i8::MAX as i64;
    const ZERO: u8 = 0;
    type Le = u8;

    fn encode(raw: u64) -> u8 {
        raw as u8
    }
    fn decode(le: u8) -> u64 {
        u64::from(le)
    }
    fn encode_signed(v: i64) -> u8 {
        v as i8 as u8
    }
    fn decode_signed(le: u8) -> i64 {
        i64::from(le as i8)
    }
}

macro_rules! impl_width_le {
    ($t:ty, $le:ident, $bytes:expr, $s:ty) => {
        impl sealed::Sealed for $t {}

        #[allow(clippy::unnecessary_cast)]
        impl Width for $t {
            const BYTES: usize = $bytes;
            const MAX: u64 = <$t>::MAX as u64;
            const SIGNED_MIN: i64 = <$s>::MIN as i64;
            const SIGNED_MAX: i64 = <$s>::MAX as i64;
            const ZERO: $le = $le::from_bytes([0; $bytes]);
            type Le = $le;

            fn encode(raw: u64) -> $le {
                $le::new(raw as $t)
            }
            fn decode(le: $le) -> u64 {
                u64::from(le.get())
            }
            fn encode_signed(v: i64) -> $le {
                $le::new(v as $s as $t)
            }
            fn decode_signed(le: $le) -> i64 {
                i64::from(le.get() as $s)
            }
        }
    };
}

impl_width_le!(u16, U16, 2, i16);
impl_width_le!(u32, U32, 4, i32);
impl_width_le!(u64, U64, 8, i64);
````

````rust
//! The four link types and the [`Link`] trait.

use core::fmt;
use core::hash::{Hash, Hasher};
use core::marker::PhantomData;

use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};

use crate::{LinkError, Width};

/// What a link decodes to, before any bounds check.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Target {
    /// The link is null.
    Null,
    /// The link refers to this element index.
    Index(usize),
    /// The decoded index is outside `0..=usize::MAX`. Only relative links can produce this.
    Invalid,
}

/// A link to an element of type `T`.
pub trait Link<T>: Copy {
    /// Decodes the link. `owner` is the index of the element that stores the link; absolute
    /// links ignore it.
    fn target(self, owner: usize) -> Target;

    /// True if the link is null, or its target is a valid index into a region of `len` elements.
    fn check(self, owner: usize, len: usize) -> bool {
        match self.target(owner) {
            Target::Null => true,
            Target::Index(i) => i < len,
            Target::Invalid => false,
        }
    }
}

macro_rules! link_type {
    ($(#[$doc:meta])* $name:ident) => {
        $(#[$doc])*
        #[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned)]
        #[repr(C)]
        pub struct $name<T, W: Width>(W::Le, PhantomData<fn() -> T>);

        impl<T, W: Width> Clone for $name<T, W> {
            fn clone(&self) -> Self {
                *self
            }
        }

        impl<T, W: Width> Copy for $name<T, W> {}

        impl<T, W: Width> PartialEq for $name<T, W> {
            fn eq(&self, other: &Self) -> bool {
                self.0 == other.0
            }
        }

        impl<T, W: Width> Eq for $name<T, W> {}

        impl<T, W: Width> Hash for $name<T, W> {
            fn hash<H: Hasher>(&self, state: &mut H) {
                self.0.hash(state);
            }
        }
    };
}

link_type! {
    /// An absolute link: the index of the target element. Never null.
    ///
    /// The width bounds the region size: `Abs<T, u16>` can address 65,536 elements.
    Abs
}

link_type! {
    /// An optional absolute link. Stores `index + 1`; stored 0 is null.
    ///
    /// Addresses one element fewer than [`Abs`] of the same width.
    OptAbs
}

link_type! {
    /// A relative link: the signed element delta `target - owner`, where `owner` is the index of
    /// the element that stores the link. Never null; delta 0 is the owner itself.
    ///
    /// The width bounds the link distance, not the region size.
    Rel
}

link_type! {
    /// An optional relative link. Stored delta 0 is null, so a non-null link cannot point at
    /// its own owner.
    OptRel
}

impl<T, W: Width> Abs<T, W> {
    /// Creates a link to element `index`.
    pub fn new(index: usize) -> Result<Self, LinkError> {
        let v = index as u64;
        if v > W::MAX {
            return Err(LinkError::OutOfRange {
                value: index as i128,
                min: 0,
                max: i128::from(W::MAX),
            });
        }
        Ok(Self(W::encode(v), PhantomData))
    }

    /// The target index. Saturates to `usize::MAX` if the stored value exceeds `usize`.
    pub fn index(self) -> usize {
        usize::try_from(W::decode(self.0)).unwrap_or(usize::MAX)
    }
}

impl<T, W: Width> OptAbs<T, W> {
    /// The null link.
    pub const NULL: Self = Self(W::ZERO, PhantomData);

    /// Creates a link to element `index`, or the null link for `None`.
    pub fn new(index: Option<usize>) -> Result<Self, LinkError> {
        let Some(i) = index else {
            return Ok(Self::NULL);
        };
        match (i as u64).checked_add(1) {
            Some(stored) if stored <= W::MAX => Ok(Self(W::encode(stored), PhantomData)),
            _ => Err(LinkError::OutOfRange {
                value: i as i128,
                min: 0,
                max: i128::from(W::MAX) - 1,
            }),
        }
    }

    /// The target index, or `None` for null. Saturates to `usize::MAX` if the stored value
    /// exceeds `usize`.
    pub fn get(self) -> Option<usize> {
        match W::decode(self.0) {
            0 => None,
            stored => Some(usize::try_from(stored - 1).unwrap_or(usize::MAX)),
        }
    }
}

impl<T, W: Width> Default for OptAbs<T, W> {
    fn default() -> Self {
        Self::NULL
    }
}

fn delta_between<W: Width>(owner: usize, target: usize) -> Result<i64, LinkError> {
    let delta = target as i128 - owner as i128;
    let (min, max) = (i128::from(W::SIGNED_MIN), i128::from(W::SIGNED_MAX));
    if delta < min || delta > max {
        return Err(LinkError::OutOfRange {
            value: delta,
            min,
            max,
        });
    }
    Ok(delta as i64)
}

impl<T, W: Width> Rel<T, W> {
    /// Creates a link from the element at `owner` to the element at `target`.
    pub fn new(owner: usize, target: usize) -> Result<Self, LinkError> {
        Ok(Self(
            W::encode_signed(delta_between::<W>(owner, target)?),
            PhantomData,
        ))
    }

    /// The stored delta.
    pub fn delta(self) -> i64 {
        W::decode_signed(self.0)
    }
}

impl<T, W: Width> OptRel<T, W> {
    /// The null link.
    pub const NULL: Self = Self(W::ZERO, PhantomData);

    /// Creates a link from the element at `owner` to the element at `target`, or the null link
    /// for `None`. Fails with [`LinkError::NullCollision`] if `target == owner`.
    pub fn new(owner: usize, target: Option<usize>) -> Result<Self, LinkError> {
        match target {
            None => Ok(Self::NULL),
            Some(t) if t == owner => Err(LinkError::NullCollision),
            Some(t) => Ok(Self(
                W::encode_signed(delta_between::<W>(owner, t)?),
                PhantomData,
            )),
        }
    }

    /// The stored delta, or `None` for null.
    pub fn delta(self) -> Option<i64> {
        match W::decode_signed(self.0) {
            0 => None,
            delta => Some(delta),
        }
    }
}

impl<T, W: Width> Default for OptRel<T, W> {
    fn default() -> Self {
        Self::NULL
    }
}

fn relative_target(owner: usize, delta: i64) -> Target {
    match usize::try_from(owner as i128 + i128::from(delta)) {
        Ok(index) => Target::Index(index),
        Err(_) => Target::Invalid,
    }
}

impl<T, W: Width> Link<T> for Abs<T, W> {
    fn target(self, _owner: usize) -> Target {
        Target::Index(self.index())
    }
}

impl<T, W: Width> Link<T> for OptAbs<T, W> {
    fn target(self, _owner: usize) -> Target {
        match self.get() {
            None => Target::Null,
            Some(index) => Target::Index(index),
        }
    }
}

impl<T, W: Width> Link<T> for Rel<T, W> {
    fn target(self, owner: usize) -> Target {
        relative_target(owner, self.delta())
    }
}

impl<T, W: Width> Link<T> for OptRel<T, W> {
    fn target(self, owner: usize) -> Target {
        match self.delta() {
            None => Target::Null,
            Some(delta) => relative_target(owner, delta),
        }
    }
}

    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
````

````rust
//! Regions and cursors: bounds-checked link resolution.

use crate::{Dangling, Link, Target};

/// A contiguous array of `T` against which links are resolved.
///
/// Every resolution is bounds-checked, so a link applied to the wrong region, a corrupted
/// link or a dangling link yields `None` or `Err`, never undefined behavior.
pub trait Region<T> {
    /// The elements of the region.
    fn as_slice(&self) -> &[T];

    /// Number of elements.
    fn len(&self) -> usize {
        self.as_slice().len()
    }

    /// True if the region has no elements.
    fn is_empty(&self) -> bool {
        self.as_slice().is_empty()
    }

    /// The element at `index`, if any.
    fn get(&self, index: usize) -> Option<&T> {
        self.as_slice().get(index)
    }

    /// Resolves `link`, owned by the element at `owner`. `None` if the link is null, invalid,
    /// or its target is outside the region.
    fn follow<L: Link<T>>(&self, owner: usize, link: L) -> Option<(usize, &T)> {
        match link.target(owner) {
            Target::Index(index) => self.get(index).map(|element| (index, element)),
            Target::Null | Target::Invalid => None,
        }
    }

    /// Resolves `link`, distinguishing null (`Ok(None)`) from a dangling target (`Err`).
    fn try_follow<L: Link<T>>(
        &self,
        owner: usize,
        link: L,
    ) -> Result<Option<(usize, &T)>, Dangling> {
        match link.target(owner) {
            Target::Null => Ok(None),
            Target::Index(index) => match self.get(index) {
                Some(element) => Ok(Some((index, element))),
                None => Err(Dangling { owner }),
            },
            Target::Invalid => Err(Dangling { owner }),
        }
    }

    /// A cursor at `index`, or `None` if `index` is outside the region.
    fn cursor(&self, index: usize) -> Option<Cursor<'_, T>> {
        let items = self.as_slice();
        (index < items.len()).then_some(Cursor { items, index })
    }
}

/// A position in a region: the element slice and the index of the current element.
///
/// The index is always in bounds, so [`Cursor::get`] never panics.
pub struct Cursor<'a, T> {
    items: &'a [T],
    index: usize,
}

impl<T> Clone for Cursor<'_, T> {
    fn clone(&self) -> Self {
        *self
    }
}

impl<T> Copy for Cursor<'_, T> {}

impl<'a, T> Cursor<'a, T> {
    /// Index of the current element.
    pub fn index(&self) -> usize {
        self.index
    }

    /// The current element.
    pub fn get(&self) -> &'a T {
        &self.items[self.index]
    }

    /// Follows a link stored in the current element. `None` if null, invalid or out of bounds.
    pub fn follow<L: Link<T>>(&self, link: L) -> Option<Cursor<'a, T>> {
        match link.target(self.index) {
            Target::Index(index) if index < self.items.len() => Some(Cursor {
                items: self.items,
                index,
            }),
            _ => None,
        }
    }

    /// Follows a link stored in the current element, distinguishing null from dangling.
    pub fn try_follow<L: Link<T>>(&self, link: L) -> Result<Option<Cursor<'a, T>>, Dangling> {
        match link.target(self.index) {
            Target::Null => Ok(None),
            Target::Index(index) if index < self.items.len() => Ok(Some(Cursor {
                items: self.items,
                index,
            })),
            Target::Index(_) | Target::Invalid => Err(Dangling { owner: self.index }),
        }
    }
}
````

//! The append-only arena.

use alloc::vec::Vec;
use core::fmt;

use crate::Region;

/// An append-only array of `T` addressed by index.
///
/// There is no removal, insertion or reordering, so the index of an element never changes
/// and links held inside the arena never dangle. `clear` is the exception: it invalidates
/// every index at once.
///
/// # Examples
///
/// ```
/// use rustlink::{Arena, OptAbs, Region};
///
/// #[derive(Clone, Copy)]
/// struct Node {
///     value: u32,
///     next: OptAbs<Node, u16>,
/// }
///
/// let mut arena = Arena::new();
/// let tail = arena.push(Node { value: 2, next: OptAbs::NULL });
/// let head = arena.push(Node { value: 1, next: OptAbs::new(Some(tail)).unwrap() });
///
/// let first = arena.cursor(head).unwrap();
/// let second = first.follow(first.get().next).unwrap();
/// assert_eq!(second.get().value, 2);
/// ```
///
/// A link only resolves in a region of the element type it was made for:
///
/// ```compile_fail,E0277
/// use rustlink::{Abs, Arena, Region};
///
/// struct A;
/// struct B;
///
/// let arena: Arena<B> = Arena::new();
/// let link: Abs<A, u16> = Abs::new(0).unwrap();
/// let _ = arena.follow(0, link);
/// ```
pub struct Arena<T> {
    items: Vec<T>,
}

impl<T> Arena<T> {
    /// An empty arena.
    pub fn new() -> Self {
        Self { items: Vec::new() }
    }

    /// An empty arena with room for `capacity` elements.
    pub fn with_capacity(capacity: usize) -> Self {
        Self {
            items: Vec::with_capacity(capacity),
        }
    }

    /// Appends `value` and returns its index.
    pub fn push(&mut self, value: T) -> usize {
        self.items.push(value);
        self.items.len() - 1
    }

    /// Mutable access to the element at `index`, for patching links after construction.
    pub fn get_mut(&mut self, index: usize) -> Option<&mut T> {
        self.items.get_mut(index)
    }

    /// Removes every element. All indices become invalid.
    pub fn clear(&mut self) {
        self.items.clear();
    }

    /// Consumes the arena and returns its elements.
    pub fn into_vec(self) -> Vec<T> {
        self.items
    }
}

impl<T> Default for Arena<T> {
    fn default() -> Self {
        Self::new()
    }
}

impl<T: fmt::Debug> fmt::Debug for Arena<T> {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.debug_list().entries(&self.items).finish()
    }
}

impl<T> Region<T> for Arena<T> {
    fn as_slice(&self) -> &[T] {
        &self.items
    }
}

//! The [`Links`] trait and the [`impl_links!`](crate::impl_links) macro.

/// Element types that can live in a blob.
///
/// Implement it with [`impl_links!`](crate::impl_links).
pub trait Links {
    /// A user-chosen layout identifier, stored in the blob header. Change it whenever the
    /// element layout changes.
    const SCHEMA: u64;

    /// True if every same-region link in `self` is null or in range for a region of `len`
    /// elements. `owner` is the index of `self`.
    fn check_links(&self, owner: usize, len: usize) -> bool;
}

/// Implements [`Links`] for a node type.
///
/// ```
/// use rustlink::{impl_links, OptAbs};
/// use zerocopy::byteorder::little_endian::U32;
/// use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};
///
/// #[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned)]
/// #[repr(C)]
/// struct Node {
///     key: U32,
///     left: OptAbs<Node, u32>,
///     right: OptAbs<Node, u32>,
/// }
///
/// impl_links!(Node, schema = 0x524C_4E4B_0001, links = [left, right]);
/// ```
///
/// List only links into the same region. Links into another region are not range-checked by
/// blob verification; they stay bounds-checked whenever they are followed.
#[macro_export]
macro_rules! impl_links {
    ($node:ty, schema = $schema:expr, links = [$($field:ident),* $(,)?]) => {
        impl $crate::Links for $node {
            const SCHEMA: u64 = $schema;

            fn check_links(&self, owner: usize, len: usize) -> bool {
                true $(&& $crate::Link::<$node>::check(self.$field, owner, len))*
            }
        }
    };
}

````rust
/// Flips bytes of an image and checks the safety property: either `verify` rejects it, or every

fn assert_tamper_safe<
    N: BstNode
        + rustlink::Links
        + zerocopy::FromBytes
        + zerocopy::KnownLayout
        + zerocopy::Immutable
        + zerocopy::Unaligned,
>(
    image: &[u8],
    values: impl Fn(u8) -> Vec<u8>,
) {
    for offset in 0..image.len() {
        for value in values(image[offset]) {
            let mut tampered = image.to_vec();

                    assert!(view.try_follow(index, node.left()).is_ok());
                    assert!(view.try_follow(index, node.right()).is_ok());
                }
            }
        }
    }
}
````

````rust
//! Narrow typed links: 1, 2, 4 or 8 byte offsets that replace 8-byte pointers inside
//! pointer-dense data structures.
//!
//! A link is stored as a little-endian offset of a chosen [`Width`] and is resolved against a
//! [`Region`] (a slice of elements) with a bounds check. Two forms exist:
//!
//! * [`Abs`] / [`OptAbs`]: an element index. The width bounds the region size.
//! * [`Rel`] / [`OptRel`]: a signed element delta from the *owner*, the element that stores the
//!   link. The width bounds the link distance, so a region can be arbitrarily large when links
//!   are local.
//!
//! All link types are `Copy`, have alignment 1 and implement the `zerocopy` traits, so node
//! types that contain them can derive the same traits. An [`Arena`] of such nodes can be
//! frozen into a position-independent blob and read back with [`BlobRef::verify`].

#![forbid(unsafe_code)]

mod blob;
mod error;
mod link;
mod links;
mod region;
mod width;

pub use arena::Arena;
pub use blob::{BlobRef, HEADER_LEN};
pub use error::{Dangling, LinkError, VerifyError};
pub use link::{Abs, Link, OptAbs, OptRel, Rel, Target};
pub use links::Links;
pub use region::{Cursor, Region};
pub use width::Width;
````

````rust
//! Frozen, verified, position-independent blobs.

use alloc::vec::Vec;

use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};

use crate::{Arena, Links, Region, VerifyError};

/// Length of the blob header in bytes.
pub const HEADER_LEN: usize = 32;

const MAGIC: [u8; 8] = *b"RLNKBLOB";
const VERSION: u32 = 1;

fn read_u32(bytes: &[u8], at: usize) -> u32 {
    u32::from_le_bytes([bytes[at], bytes[at + 1], bytes[at + 2], bytes[at + 3]])
}

fn read_u64(bytes: &[u8], at: usize) -> u64 {
    u64::from_le_bytes([
        bytes[at],
        bytes[at + 1],
        bytes[at + 2],
        bytes[at + 3],
        bytes[at + 4],
        bytes[at + 5],
        bytes[at + 6],
        bytes[at + 7],
    ])
}

impl<T> Arena<T>
where
    T: IntoBytes + Immutable + Unaligned + Links,
{
    /// Appends the blob image of this arena (header plus raw elements) to `out`.
    ///
    /// The image holds no addresses, so it can be written to a file, memory-mapped or sent to
    /// another process and read back with [`BlobRef::verify`].
    pub fn freeze_into(&self, out: &mut Vec<u8>) {
        const { assert!(size_of::<T>() > 0 && size_of::<T>() <= u32::MAX as usize) };
        let items = self.as_slice();
        out.reserve(HEADER_LEN + core::mem::size_of_val(items));
        out.extend_from_slice(&MAGIC);
        out.extend_from_slice(&VERSION.to_le_bytes());
        out.extend_from_slice(&(size_of::<T>() as u32).to_le_bytes());
        out.extend_from_slice(&T::SCHEMA.to_le_bytes());
        out.extend_from_slice(&(items.len() as u64).to_le_bytes());
        out.extend_from_slice(items.as_bytes());
    }

    /// The blob image of this arena.
    pub fn freeze(&self) -> Vec<u8> {
        let mut out = Vec::new();
        self.freeze_into(&mut out);
        out
    }
}

/// A verified, zero-copy view of a blob.
///
/// Created by [`BlobRef::verify`]. Resolve links through the [`Region`] trait.
pub struct BlobRef<'a, T> {
    items: &'a [T],
}

impl<'a, T> BlobRef<'a, T>
where
    T: FromBytes + KnownLayout + Immutable + Unaligned + Links,
{
    /// Checks `bytes` and returns a view of its elements.
    ///
    /// Verification is O(n) and allocation-free. It checks the header, the exact length, the
    /// element size and schema id, and that every same-region link of every element is null or
    /// in range. Memory safety never depends on it: links stay bounds-checked when followed.
    pub fn verify(bytes: &'a [u8]) -> Result<Self, VerifyError> {
        const { assert!(size_of::<T>() > 0 && size_of::<T>() <= u32::MAX as usize) };
        if bytes.len() < HEADER_LEN {
            return Err(VerifyError::Truncated);
        }
        if bytes[..8] != MAGIC {
            return Err(VerifyError::BadMagic);
        }
        let version = read_u32(bytes, 8);
        if version != VERSION {
            return Err(VerifyError::Version { found: version });
        }
        let elem_size = read_u32(bytes, 12);
        if elem_size as usize != size_of::<T>() {
            return Err(VerifyError::ElemSize {
                found: elem_size,
                expected: size_of::<T>() as u32,
            });
        }
        let schema = read_u64(bytes, 16);
        if schema != T::SCHEMA {
            return Err(VerifyError::Schema {
                found: schema,
                expected: T::SCHEMA,
            });
        }
        let count = read_u64(bytes, 24);
        let expected = count
            .checked_mul(u64::from(elem_size))
            .and_then(|body| body.checked_add(HEADER_LEN as u64))
            .ok_or(VerifyError::CountOverflow)?;
        let length_error = VerifyError::Length {
            expected,
            actual: bytes.len(),
        };
        if expected != bytes.len() as u64 {
            return Err(length_error);
        }
        let count = usize::try_from(count).map_err(|_| VerifyError::CountOverflow)?;
        let items = <[T]>::ref_from_bytes_with_elems(&bytes[HEADER_LEN..], count)
            .map_err(|_| length_error)?;
        for (index, element) in items.iter().enumerate() {
            if !element.check_links(index, items.len()) {
                return Err(VerifyError::BadLink { index });
            }
        }
        Ok(Self { items })
    }
}

impl<T> Region<T> for BlobRef<'_, T> {
    fn as_slice(&self) -> &[T] {
        self.items
    }
}
````

````rust
//! A tiny deterministic generator so every variant of a workload sees identical inputs.

/// xorshift64*.
#[derive(Clone, Debug)]
pub struct Rng(u64);

impl Rng {
    /// A generator for `seed`. Any seed is valid; 0 is mapped to a fixed non-zero state.
    pub fn new(seed: u64) -> Self {
        Self(if seed == 0 {
            0x9E37_79B9_7F4A_7C15
        } else {
            seed
        })
    }

    /// The next 64 random bits.
    pub fn next_u64(&mut self) -> u64 {
        let mut x = self.0;
        x ^= x >> 12;
        x ^= x << 25;
        x ^= x >> 27;
        self.0 = x;
        x.wrapping_mul(0x2545_F491_4F6C_DD1D)
    }

    /// The next 32 random bits.
    pub fn next_u32(&mut self) -> u32 {
        (self.next_u64() >> 32) as u32
    }

    /// A value in `0..bound` (`bound` must be non-zero), by multiply-shift.
    pub fn below(&mut self, bound: u64) -> u64 {
        ((u128::from(self.next_u64()) * u128::from(bound)) >> 64) as u64
    }

    /// Fisher-Yates shuffle.
    pub fn shuffle<T>(&mut self, items: &mut [T]) {
        for i in (1..items.len()).rev() {
            let j = self.below(i as u64 + 1) as usize;
            items.swap(i, j);
        }
    }
}
````

````rust
//! Robust summary statistics.

/// Median and median absolute deviation of a sample set.
#[derive(Clone, Copy, Debug, PartialEq, Default)]
pub struct Dist {
    /// The median.
    pub median: f64,
    /// The median absolute deviation from the median.
    pub mad: f64,
}

fn median_of_sorted(sorted: &[f64]) -> f64 {
    let n = sorted.len();
    if n % 2 == 1 {
        sorted[n / 2]
    } else {
        (sorted[n / 2 - 1] + sorted[n / 2]) / 2.0
    }
}

/// Median and MAD of `samples`. Panics if `samples` is empty.
pub fn dist(samples: &[f64]) -> Dist {
    assert!(!samples.is_empty(), "dist of an empty sample set");
    let mut sorted = samples.to_vec();
    sorted.sort_by(|a, b| a.total_cmp(b));
    let median = median_of_sorted(&sorted);
    let mut deviations: Vec<f64> = sorted.iter().map(|s| (s - median).abs()).collect();
    deviations.sort_by(|a, b| a.total_cmp(b));
    Dist {
        median,
        mad: median_of_sorted(&deviations),
    }
}
````

````rust
//! A counting global allocator for measuring live heap bytes.
//!
//! Install [`Counting`] as the `#[global_allocator]` of a binary. Counting is off by default so
//! timed repetitions do not pay for atomic updates; [`measure::run_reps`](crate::measure::run_reps)
//! turns it on for one warm-up repetition.

#![allow(unsafe_code)]

use std::alloc::{GlobalAlloc, Layout, System};
use std::sync::atomic::{AtomicBool, AtomicUsize, Ordering::Relaxed};

static ENABLED: AtomicBool = AtomicBool::new(false);
static LIVE: AtomicUsize = AtomicUsize::new(0);

/// Forwards to the system allocator and, while enabled, tracks live requested bytes.
pub struct Counting;

// SAFETY: every method forwards to `System`, which upholds the `GlobalAlloc` contract. The
// counters are bookkeeping only and never affect the returned pointers.
unsafe impl GlobalAlloc for Counting {
    unsafe fn alloc(&self, layout: Layout) -> *mut u8 {
        // SAFETY: the caller upholds `GlobalAlloc::alloc`'s contract, which `System` shares.
        let ptr = unsafe { System.alloc(layout) };
        if !ptr.is_null() && ENABLED.load(Relaxed) {
            LIVE.fetch_add(layout.size(), Relaxed);
        }
        ptr
    }

    unsafe fn dealloc(&self, ptr: *mut u8, layout: Layout) {
        // SAFETY: the caller upholds `GlobalAlloc::dealloc`'s contract, which `System` shares.
        unsafe { System.dealloc(ptr, layout) };
        if ENABLED.load(Relaxed) {
            LIVE.fetch_sub(layout.size(), Relaxed);
        }
    }

    unsafe fn alloc_zeroed(&self, layout: Layout) -> *mut u8 {
        // SAFETY: the caller upholds `GlobalAlloc::alloc_zeroed`'s contract.
        let ptr = unsafe { System.alloc_zeroed(layout) };
        if !ptr.is_null() && ENABLED.load(Relaxed) {
            LIVE.fetch_add(layout.size(), Relaxed);
        }
        ptr
    }

    unsafe fn realloc(&self, ptr: *mut u8, layout: Layout, new_size: usize) -> *mut u8 {
        // SAFETY: the caller upholds `GlobalAlloc::realloc`'s contract.
        let new_ptr = unsafe { System.realloc(ptr, layout, new_size) };
        if !new_ptr.is_null() && ENABLED.load(Relaxed) {
            LIVE.fetch_sub(layout.size(), Relaxed);
            LIVE.fetch_add(new_size, Relaxed);
        }
        new_ptr
    }
}

/// Turns byte counting on or off. Only blocks allocated and freed inside one enabled window
/// are accounted correctly, so enable it around a build-use-drop cycle.
pub fn set_counting(on: bool) {
    ENABLED.store(on, Relaxed);
}

/// Bytes currently live while counting is enabled; always 0 if [`Counting`] is not installed.
pub fn live_bytes() -> usize {
    LIVE.load(Relaxed)
}
````

````rust
//! The contract between workloads and the runner.

use crate::measure::{OverBudget, Params, RepStats};
use crate::stats::Dist;

/// Link-distance statistics of a structure, used to decide whether a narrow relative link can
/// represent it. Distances are `|child index - parent index|`.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Reach {
    /// Number of links measured.
    pub links: u64,
    /// Fraction of links with distance at most 127 (fits an `i8`, conservatively).
    pub within_127: f64,
    /// Fraction of links with distance at most 32,767 (fits an `i16`, conservatively).
    pub within_32767: f64,
    /// Largest distance.
    pub max_abs_delta: u64,
}

impl Default for Reach {
    fn default() -> Self {
        Reach {
            links: 0,
            within_127: 1.0,
            within_32767: 1.0,
            max_abs_delta: 0,
        }
    }
}

impl Reach {
    /// Summarises the signed deltas of every link.
    pub fn from_deltas(deltas: impl IntoIterator<Item = i64>) -> Reach {
        let (mut links, mut within_127, mut within_32767, mut max) = (0u64, 0u64, 0u64, 0u64);
        for delta in deltas {
            let distance = delta.unsigned_abs();
            links += 1;
            within_127 += u64::from(distance <= 127);
            within_32767 += u64::from(distance <= 32_767);
            max = max.max(distance);
        }
        if links == 0 {
            return Reach::default();
        }
        Reach {
            links,
            within_127: within_127 as f64 / links as f64,
            within_32767: within_32767 as f64 / links as f64,
            max_abs_delta: max,
        }
    }

    /// True if every link distance is at most `max_delta`.
    pub fn fits(&self, max_delta: i64) -> bool {
        self.max_abs_delta <= max_delta as u64
    }
}

/// How many elements, or how far apart links, a variant can represent.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Limit {
    /// No practical limit (pointers, machine-word indices, hand-written `u32` indices).
    None,
    /// Absolute links: at most this many elements.
    Abs {
        /// Largest element count the width can address.
        max_elements: u64,
    },
    /// Relative links: every link distance at most this.
    Rel {
        /// Largest representable distance.
        max_delta: i64,
    },
}

impl Limit {
    /// True if a structure of `elements` elements with link distances `reach` is representable.
    pub fn admits(&self, elements: usize, reach: &Reach) -> bool {
        match *self {
            Limit::None => true,
            Limit::Abs { max_elements } => elements as u64 <= max_elements,
            Limit::Rel { max_delta } => reach.fits(max_delta),
        }
    }
}

/// Numbers reported for one finished cell.
#[derive(Clone, Debug, PartialEq)]
pub struct Metrics {
    /// `size_of` one node in bytes (average record size for variable-size layouts).
    pub node_bytes: usize,
    /// Live heap bytes requested per node after the build; 0 when no counting allocator is installed.
    pub heap_bytes_per_node: f64,
    /// Build time in ns per node.
    pub build: Dist,
    /// Traversal time in ns per unit of work.
    pub traverse: Dist,
    /// What one unit of traversal work is: `"lookup"`, `"visit"`, `"edge"` or `"node"`.
    pub unit: &'static str,
    /// Link-distance statistics, when the workload measured them.
    pub reach: Option<Reach>,
}

/// What running one variant of a workload produced.
#[derive(Clone, Debug, PartialEq)]
pub enum Outcome {
    /// The variant ran.
    Done(Metrics),
    /// The variant's links cannot represent this workload at this size.
    Unreachable(Reach),
    /// The cell was not run, with the reason.
    Skipped(String),
}

impl Outcome {
    /// Converts the result of [`run_reps`](crate::measure::run_reps) into an outcome.
    pub fn from_reps(
        result: Result<RepStats, OverBudget>,
        node_bytes: usize,
        unit: &'static str,
        reach: Option<Reach>,
    ) -> Outcome {
        match result {
            Ok(stats) => Outcome::Done(Metrics {
                node_bytes,
                heap_bytes_per_node: stats.heap_bytes_per_node,
                build: stats.build,
                traverse: stats.traverse,
                unit,
                reach,
            }),
            Err(over) => Outcome::Skipped(format!(
                "over the time budget: predicted {:.1?} for the remaining repetitions, budget {:.1?}",
                over.predicted, over.budget
            )),
        }
    }
}

/// A benchmark workload: one data structure task with several link-representation variants.
pub trait Workload: Sync {
    /// Stable name, e.g. `"bst-random"`.
    fn name(&self) -> &'static str;

    /// Variant names this workload accepts.
    fn variants(&self) -> &'static [&'static str];

    /// Largest `n` the default sweep runs for this workload.
    fn max_n(&self) -> usize {
        1 << 24
    }

    /// Rough upper bound of heap bytes per unit of `n`, used by the sweep to skip cells that
    /// would not fit in memory.
    fn footprint_per_n(&self) -> usize {
        64
    }

    /// Runs one variant. `Err` means the request itself was invalid (for example an unknown
    /// variant name).
    fn run(&self, variant: &str, params: &Params) -> Result<Outcome, String>;
}
````

````rust
//! The run loop and the measurement record exchanged between `rlb`, `sweep` and the report.

use std::hint::black_box;
use std::time::{Duration, Instant};

use crate::alloc;
use crate::stats::{Dist, dist};
use crate::workload::{Outcome, Reach};

/// Parameters shared by every workload run.
#[derive(Clone, Debug, PartialEq)]
pub struct Params {
    /// Workload size: nodes for trees, vertices for graphs.
    pub n: usize,
    /// Repetitions including one discarded warm-up; at least 2.
    pub reps: usize,
    /// Seed for every random input.
    pub seed: u64,
    /// The cell is skipped if the warm-up repetition predicts the remaining ones exceed this.
    pub budget: Duration,
}

impl Params {
    /// Default parameters for size `n`: 6 repetitions (5 measured), seed 1, 120 s budget.
    pub fn new(n: usize) -> Self {
        Params {
            n,
            reps: 6,
            seed: 1,
            budget: Duration::from_secs(120),
        }
    }
}

/// What one traversal pass did.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Pass {
    /// A value derived from the work; consumed with `black_box` so it cannot be optimised away.
    pub checksum: u64,
    /// Units of work done (lookups, node visits or edge scans); the traverse metric is ns per unit.
    pub units: u64,
}

/// Statistics over the measured repetitions.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct RepStats {
    /// Live heap bytes requested per node after the build (0 without the counting allocator).
    pub heap_bytes_per_node: f64,
    /// Build time in ns per node.
    pub build: Dist,
    /// Traversal time in ns per unit of work.
    pub traverse: Dist,
}

/// The warm-up repetition predicted the cell would exceed its time budget.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct OverBudget {
    /// Predicted time of the remaining repetitions.
    pub predicted: Duration,
    /// The budget.
    pub budget: Duration,
}

/// Runs `build` and `traverse` `p.reps` times. Repetition 0 is a warm-up: it runs with the
/// counting allocator enabled to measure heap bytes, and its duration decides whether the cell
/// fits the time budget. The other repetitions are timed with counting off.
///
/// `nodes` normalises build time; each pass reports its own unit count for traversal time.
pub fn run_reps<S>(
    p: &Params,
    nodes: u64,
    mut build: impl FnMut() -> S,
    mut traverse: impl FnMut(&S) -> Pass,
) -> Result<RepStats, OverBudget> {
    assert!(
        p.reps >= 2,
        "need at least one warm-up and one measured repetition"
    );
    let nodes = nodes.max(1);

    let started = Instant::now();
    alloc::set_counting(true);
    let before = alloc::live_bytes();
    let structure = build();
    let after = alloc::live_bytes();
    black_box(traverse(&structure).checksum);
    drop(structure);
    alloc::set_counting(false);
    let warm_up = started.elapsed();
    let predicted = warm_up * (p.reps as u32 - 1);
    if predicted > p.budget {
        return Err(OverBudget {
            predicted,
            budget: p.budget,
        });
    }

    let mut build_ns = Vec::with_capacity(p.reps - 1);
    let mut traverse_ns = Vec::with_capacity(p.reps - 1);
    for _ in 1..p.reps {
        let t = Instant::now();
        let structure = build();
        let built = t.elapsed();
        let t = Instant::now();
        let pass = traverse(black_box(&structure));
        let traversed = t.elapsed();
        black_box(pass.checksum);
        build_ns.push(built.as_nanos() as f64 / nodes as f64);
        traverse_ns.push(traversed.as_nanos() as f64 / pass.units.max(1) as f64);
        drop(structure);
    }
    Ok(RepStats {
        heap_bytes_per_node: after.saturating_sub(before) as f64 / nodes as f64,
        build: dist(&build_ns),
        traverse: dist(&traverse_ns),
    })
}

impl Measurement {
    /// Builds a measurement from a workload outcome. Process-level fields stay zero.
    pub fn from_outcome(workload: &str, variant: &str, p: &Params, outcome: &Outcome) -> Self {
        let mut m = Measurement {
            workload: workload.to_owned(),
            variant: variant.to_owned(),
            n: p.n as u64,
            reps: p.reps as u64,
            seed: p.seed,
            ..Measurement::default()
        };
        match outcome {
            Outcome::Done(metrics) => {
                m.status = "done".to_owned();
                m.unit = metrics.unit.to_owned();
                m.node_bytes = metrics.node_bytes as u64;
                m.heap_bytes_per_node = metrics.heap_bytes_per_node;
                m.build_ns_median = metrics.build.median;
                m.build_ns_mad = metrics.build.mad;
                m.traverse_ns_median = metrics.traverse.median;
                m.traverse_ns_mad = metrics.traverse.mad;
                if let Some(reach) = &metrics.reach {
                    m.set_reach(reach);
                }
            }
            Outcome::Unreachable(reach) => {
                m.status = "unreachable".to_owned();
                m.note = format!(
                    "links do not fit: max distance {}, {:.1}% within 127, {:.1}% within 32767",
                    reach.max_abs_delta,
                    reach.within_127 * 100.0,
                    reach.within_32767 * 100.0
                );
                m.set_reach(reach);
            }
            Outcome::Skipped(reason) => {
                m.status = "skipped".to_owned();
                m.note = reason.clone();
            }
        }
        m
    }

    fn set_reach(&mut self, reach: &Reach) {
        self.reach_links = reach.links;
        self.reach_within_127 = reach.within_127;
        self.reach_within_32767 = reach.within_32767;
        self.reach_max_abs_delta = reach.max_abs_delta;
    }

    /// Serialises to one line of flat JSON.
    pub fn to_json(&self) -> String {
        let mut obj = JsonObject::default();

        obj.string("variant", &self.variant);

        obj.float("build_ns_median", self.build_ns_median);
        obj.float("build_ns_mad", self.build_ns_mad);
        obj.float("traverse_ns_median", self.traverse_ns_median);
        obj.float("traverse_ns_mad", self.traverse_ns_mad);
        obj.number("peak_rss_kib", self.peak_rss_kib);
        obj.number("minor_faults", self.minor_faults);
        obj.number("major_faults", self.major_faults);
        obj.number("reach_links", self.reach_links);
        obj.float("reach_within_127", self.reach_within_127);

    /// Parses a line produced by [`Measurement::to_json`]. Unknown keys are ignored and missing
    /// keys keep their default.
    pub fn from_json(line: &str) -> Result<Self, String> {
        let fields = parse_flat_object(line)?;
        let text = |key: &str| -> String {
            match fields.iter().find(|(k, _)| k == key) {
                Some((_, Value::Str(s))) => s.clone(),
                Some((_, Value::Num(s))) => s.clone(),
                None => String::new(),
            }
        };
        let int = |key: &str| -> u64 {
            let t = text(key);
            t.parse::<u64>()
                .unwrap_or_else(|_| t.parse::<f64>().map_or(0, |f| f as u64))
        };
        let float = |key: &str| -> f64 { text(key).parse::<f64>().unwrap_or(0.0) };
        Ok(Measurement {
            workload: text("workload"),
            variant: text("variant"),
            n: int("n"),
            reps: int("reps"),
            seed: int("seed"),
            status: text("status"),
            note: text("note"),
            unit: text("unit"),
            node_bytes: int("node_bytes"),
            heap_bytes_per_node: float("heap_bytes_per_node"),
            build_ns_median: float("build_ns_median"),
            build_ns_mad: float("build_ns_mad"),
            traverse_ns_median: float("traverse_ns_median"),
            traverse_ns_mad: float("traverse_ns_mad"),
            peak_rss_kib: int("peak_rss_kib"),
            minor_faults: int("minor_faults"),
            major_faults: int("major_faults"),
            reach_links: int("reach_links"),
            reach_within_127: float("reach_within_127"),
            reach_within_32767: float("reach_within_32767"),
            reach_max_abs_delta: int("reach_max_abs_delta"),
        })
    }

#[derive(Default)]
struct JsonObject {
    buf: String,
}

impl JsonObject {
    fn key(&mut self, key: &str) {
        self.buf.push(if self.buf.is_empty() { '{' } else { ',' });
        self.buf.push('"');
        self.buf.push_str(key);
        self.buf.push_str("\":");
    }

    fn string(&mut self, key: &str, value: &str) {
        self.key(key);
        self.buf.push('"');
        for c in value.chars() {
            match c {
                '"' => self.buf.push_str("\\\""),
                '\\' => self.buf.push_str("\\\\"),
                '\n' => self.buf.push_str("\\n"),
                '\r' => self.buf.push_str("\\r"),
                '\t' => self.buf.push_str("\\t"),
                c if (c as u32) < 0x20 => self.buf.push_str(&format!("\\u{:04x}", c as u32)),
                c => self.buf.push(c),
            }
        }
        self.buf.push('"');
    }

    fn number(&mut self, key: &str, value: u64) {
        self.key(key);
        self.buf.push_str(&value.to_string());
    }

    fn float(&mut self, key: &str, value: f64) {
        self.key(key);
        let value = if value.is_finite() { value } else { 0.0 };
        self.buf.push_str(&format!("{value}"));
    }

    fn finish(mut self) -> String {
        self.buf.push('}');
        self.buf
    }
}

enum Value {
    Str(String),
    Num(String),
}

fn parse_flat_object(line: &str) -> Result<Vec<(String, Value)>, String> {
    let mut chars = line.trim().chars().peekable();
    let mut fields = Vec::new();
    let skip_ws = |chars: &mut std::iter::Peekable<std::str::Chars<'_>>| {
        while chars.peek().is_some_and(|c| c.is_whitespace()) {
            chars.next();
        }
    };
    let parse_string =
        |chars: &mut std::iter::Peekable<std::str::Chars<'_>>| -> Result<String, String> {
            if chars.next() != Some('"') {
                return Err("expected a string".to_owned());
            }
            let mut out = String::new();
            loop {
                match chars.next().ok_or("unterminated string")? {
                    '"' => return Ok(out),
                    '\\' => match chars.next().ok_or("unterminated escape")? {
                        '"' => out.push('"'),
                        '\\' => out.push('\\'),
                        'n' => out.push('\n'),
                        'r' => out.push('\r'),
                        't' => out.push('\t'),
                        'u' => {
                            let hex: String = chars.by_ref().take(4).collect();
                            let code = u32::from_str_radix(&hex, 16).map_err(|e| e.to_string())?;
                            out.push(char::from_u32(code).ok_or("bad unicode escape")?);
                        }
                        other => return Err(format!("unknown escape \\{other}")),
                    },
                    c => out.push(c),
                }
            }
        };

    skip_ws(&mut chars);
    if chars.next() != Some('{') {
        return Err("expected `{`".to_owned());
    }
    loop {
        skip_ws(&mut chars);
        if chars.peek() == Some(&'}') {
            chars.next();
            return Ok(fields);
        }
        let key = parse_string(&mut chars)?;
        skip_ws(&mut chars);
        if chars.next() != Some(':') {
            return Err("expected `:`".to_owned());
        }
        skip_ws(&mut chars);
        let value = if chars.peek() == Some(&'"') {
            Value::Str(parse_string(&mut chars)?)
        } else {
            let mut token = String::new();
            while chars
                .peek()
                .is_some_and(|c| !matches!(c, ',' | '}') && !c.is_whitespace())
            {
                token.push(chars.next().unwrap_or_default());
            }
            Value::Num(if token == "null" {
                "0".to_owned()
            } else {
                token
            })
        };
        fields.push((key, value));
        skip_ws(&mut chars);
        match chars.next() {
            Some(',') => {}
            Some('}') => return Ok(fields),
            _ => return Err("expected `,` or `}`".to_owned()),
        }
    }
}
````

````rust
//! Tree plans: link-representation-independent descriptions of the trees the workloads build.

use crate::rng::Rng;
use crate::workload::Reach;

/// Expression operation: a leaf constant.
pub const OP_LEAF: u32 = 0;
/// Expression operation: wrapping addition of both operands.
pub const OP_ADD: u32 = 1;
/// Expression operation: wrapping negation of the first operand.
pub const OP_NEG: u32 = 2;
/// Expression operation: wrapping multiplication of both operands.
pub const OP_MUL: u32 = 3;
/// Mask of the 24-bit constant stored in a leaf payload.
pub const CONST_MASK: u32 = 0xFF_FFFF;

/// One node of a plan: a payload and its children as indices of earlier nodes.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Spec {
    /// BST: the key. Expression tree: the operation in the high 8 bits and, for leaves, a 24-bit
    /// constant in the low bits.
    pub payload: u32,
    /// First child (BST: smaller keys; expression: first operand).
    pub a: Option<u32>,
    /// Second child (BST: larger keys; expression: second operand).
    pub b: Option<u32>,
}

/// A tree described independently of any link representation.
///
/// Every child index is smaller than its parent's index and the root is the last node, so
/// creating the nodes in order always has the children available before their parents.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Plan {
    /// Nodes in creation order.
    pub nodes: Vec<Spec>,
}

impl Plan {
    /// Index of the root (the last node), or `None` for an empty plan.
    pub fn root(&self) -> Option<usize> {
        self.nodes.len().checked_sub(1)
    }

    /// Distances of every link, `child index - parent index`.
    pub fn reach(&self) -> Reach {
        Reach::from_deltas(self.nodes.iter().enumerate().flat_map(|(parent, spec)| {
            [spec.a, spec.b]
                .into_iter()
                .flatten()
                .map(move |child| i64::from(child) - parent as i64)
        }))
    }

    /// A perfectly balanced BST over the keys `0..n`: payload is the key, `a` the smaller side.
    /// Children are created before parents (post-order).
    pub fn balanced_bst(n: usize) -> Plan {
        fn build(nodes: &mut Vec<Spec>, lo: usize, hi: usize) -> Option<u32> {
            if lo >= hi {
                return None;
            }
            let mid = lo + (hi - lo) / 2;
            let a = build(nodes, lo, mid);
            let b = build(nodes, mid + 1, hi);
            nodes.push(Spec {
                payload: mid as u32,
                a,
                b,
            });
            Some((nodes.len() - 1) as u32)
        }
        let mut nodes = Vec::with_capacity(n);
        build(&mut nodes, 0, n);
        Plan { nodes }
    }

    /// A random expression tree of at least `n` nodes (`n >= 1`), built bottom-up with a stack of
    /// unfinished subtrees, so operands are always created before their operation.
    pub fn expression(n: usize, seed: u64) -> Plan {
        assert!(n >= 1, "an expression needs at least one node");
        let mut rng = Rng::new(seed);
        let mut nodes: Vec<Spec> = Vec::with_capacity(n + 64);
        let mut stack: Vec<u32> = Vec::new();
        while nodes.len() < n {
            let choice = rng.below(10);
            let index = nodes.len() as u32;
            if stack.len() >= 2 && choice < 4 {
                let (b, a) = (stack.pop(), stack.pop());
                let op = 1 + 2 * rng.below(2) as u32; // OP_ADD or OP_MUL
                nodes.push(Spec {
                    payload: op << 24,
                    a,
                    b,
                });
            } else if !stack.is_empty() && choice < 6 {
                nodes.push(Spec {
                    payload: OP_NEG << 24,
                    a: stack.pop(),
                    b: None,
                });
            } else {
                nodes.push(Spec {
                    payload: rng.next_u32() & CONST_MASK,
                    a: None,
                    b: None,
                });
            }
            stack.push(index);
        }
        while stack.len() > 1 {
            let index = nodes.len() as u32;
            let (b, a) = (stack.pop(), stack.pop());
            nodes.push(Spec {
                payload: OP_ADD << 24,
                a,
                b,
            });
            stack.push(index);
        }
        Plan { nodes }
    }
}

/// Evaluates a plan directly, independent of every variant. Returns the root's value.
pub fn reference_eval(plan: &Plan) -> u32 {
    let mut values: Vec<u32> = Vec::with_capacity(plan.nodes.len());
    for spec in &plan.nodes {
        let value_of = |child: Option<u32>| child.map_or(0, |i| values[i as usize]);
        let value = match spec.payload >> 24 {
            OP_NEG => value_of(spec.a).wrapping_neg(),
            OP_ADD => value_of(spec.a).wrapping_add(value_of(spec.b)),
            OP_MUL => value_of(spec.a).wrapping_mul(value_of(spec.b)),
            _ => spec.payload & CONST_MASK,
        };
        values.push(value);
    }
    values.last().copied().unwrap_or(0)
}
````

````rust
//!
//! Every variant stores the same logical tree (a payload and two optional children per node) and
//! implements [`TreeView`] for traversal and [`TreeBuild`] for construction, so one generic
//! algorithm runs unchanged on pointers, hand-written indices and narrow rustlink links.

/// Read access to a tree through a cheap, copyable reference type.
pub trait TreeView {
    /// A reference to one node: a pointer, an index or a cursor.
    type Ref<'a>: Copy
    where
        Self: 'a;

    /// The root, if the tree is not empty.
    fn root(&self) -> Option<Self::Ref<'_>>;
    /// The payload of `r`.
    fn payload(&self, r: Self::Ref<'_>) -> u32;
    /// The first child of `r` (BST: smaller keys).
    fn a<'a>(&'a self, r: Self::Ref<'a>) -> Option<Self::Ref<'a>>;
    /// The second child of `r` (BST: larger keys).
    fn b<'a>(&'a self, r: Self::Ref<'a>) -> Option<Self::Ref<'a>>;
}

/// Construction of a tree in one link representation.
pub trait TreeBuild: TreeView + Sized {
    /// `size_of` one node in bytes.
    const NODE_BYTES: usize;
    /// What the representation can address.
    const LIMIT: Limit;

    /// An empty tree with room for `capacity` nodes.
    fn empty(capacity: usize) -> Self;
    /// Builds the plan's tree. Children precede parents; the root is the last node.
    fn from_plan(plan: &Plan) -> Self;
    /// Top-down unbalanced BST insertion: payload is the key, `a` holds smaller keys, `b` larger
    /// ones. Duplicates are ignored and the first insertion becomes the root.
    fn insert_bst(&mut self, key: u32);
    /// Number of nodes.
    fn len(&self) -> usize;
    /// True if the tree has no nodes.
    fn is_empty(&self) -> bool {
        self.len() == 0
    }
}

/// BST lookup.
pub fn contains<V: TreeView>(view: &V, key: u32) -> bool {
    let mut cursor = view.root();
    while let Some(node) = cursor {
        let payload = view.payload(node);
        if key == payload {
            return true;
        }
        cursor = if key < payload {
            view.a(node)
        } else {
            view.b(node)
        };
    }
    false
}

/// Evaluates an expression tree with explicit stacks (no recursion). Returns the value and the
/// number of nodes visited.
pub fn eval<V: TreeView>(view: &V) -> (u32, u64) {
    enum Step {
        Enter,
        Negate,
        Combine,
    }
    let Some(root) = view.root() else {
        return (0, 0);
    };
    let mut stack = vec![(root, Step::Enter)];
    let mut values: Vec<u32> = Vec::new();
    let mut visits = 0u64;
    while let Some((node, step)) = stack.pop() {
        match step {
            Step::Enter => {
                visits += 1;
                match (view.a(node), view.b(node)) {
                    (None, _) => values.push(view.payload(node) & CONST_MASK),
                    (Some(a), None) => {
                        stack.push((node, Step::Negate));
                        stack.push((a, Step::Enter));
                    }
                    (Some(a), Some(b)) => {
                        stack.push((node, Step::Combine));
                        stack.push((b, Step::Enter));
                        stack.push((a, Step::Enter));
                    }
                }
            }
            Step::Negate => {
                let x = values.pop().expect("operand");
                debug_assert_eq!(view.payload(node) >> 24, OP_NEG);
                values.push(x.wrapping_neg());
            }
            Step::Combine => {
                let y = values.pop().expect("second operand");
                let x = values.pop().expect("first operand");
                values.push(if view.payload(node) >> 24 == OP_MUL {
                    x.wrapping_mul(y)
                } else {
                    x.wrapping_add(y)
                });
            }
        }
    }
    (values.pop().unwrap_or(0), visits)
}
````

````rust
//! The pointer baseline: every node is a separate heap allocation.

use super::{TreeBuild, TreeView};
use crate::plan::Plan;
use crate::workload::Limit;

/// One heap-allocated node.
pub struct Node {
    payload: u32,
    a: Option<Box<Node>>,
    b: Option<Box<Node>>,
}

/// A tree of boxed nodes.
pub struct BoxTree {
    root: Option<Box<Node>>,
    len: usize,
}

impl Drop for BoxTree {
    /// Drops iteratively so a very deep tree cannot overflow the call stack.
    fn drop(&mut self) {
        let mut stack: Vec<Box<Node>> = Vec::new();
        stack.extend(self.root.take());
        while let Some(mut node) = stack.pop() {
            stack.extend(node.a.take());
            stack.extend(node.b.take());
        }
    }
}

impl TreeView for BoxTree {
    type Ref<'a> = &'a Node;

    fn root(&self) -> Option<&Node> {
        self.root.as_deref()
    }

    fn payload(&self, r: &Node) -> u32 {
        r.payload
    }

    fn a<'a>(&'a self, r: &'a Node) -> Option<&'a Node> {
        r.a.as_deref()
    }

    fn b<'a>(&'a self, r: &'a Node) -> Option<&'a Node> {
        r.b.as_deref()
    }
}

impl TreeBuild for BoxTree {
    const NODE_BYTES: usize = size_of::<Node>();
    const LIMIT: Limit = Limit::None;

    fn empty(_capacity: usize) -> Self {
        BoxTree { root: None, len: 0 }
    }

    fn from_plan(plan: &Plan) -> Self {
        let mut slots: Vec<Option<Box<Node>>> = Vec::with_capacity(plan.nodes.len());
        for spec in &plan.nodes {
            let a = spec.a.and_then(|i| slots[i as usize].take());
            let b = spec.b.and_then(|i| slots[i as usize].take());
            slots.push(Some(Box::new(Node {
                payload: spec.payload,
                a,
                b,
            })));
        }
        BoxTree {
            root: slots.pop().flatten(),
            len: plan.nodes.len(),
        }
    }

    fn insert_bst(&mut self, key: u32) {
        let mut slot = &mut self.root;
        while let Some(node) = slot {
            slot = match key.cmp(&node.payload) {
                core::cmp::Ordering::Less => &mut node.a,
                core::cmp::Ordering::Greater => &mut node.b,
                core::cmp::Ordering::Equal => return,
            };
        }
        *slot = Some(Box::new(Node {
            payload: key,
            a: None,
            b: None,
        }));
        self.len += 1;
    }

    fn len(&self) -> usize {
        self.len
    }
}
````

````rust
//! Hand-written index baselines: a `Vec` of nodes with machine-word or 32-bit index links.

#![allow(clippy::unnecessary_cast)]

use super::{TreeBuild, TreeView};
use crate::plan::Plan;
use crate::workload::{Limit, Reach};

macro_rules! plain_store {
    ($(#[$doc:meta])* $store:ident, $node:ident, $link:ty) => {
        #[derive(Clone, Copy)]
        #[repr(C)]
        struct $node {
            payload: u32,
            a: $link,
            b: $link,
        }

        $(#[$doc])*
        pub struct $store {
            nodes: Vec<$node>,
            root: usize,
        }

        impl $store {
            const NIL: $link = <$link>::MAX;

            fn leaf(key: u32) -> $node {
                $node { payload: key, a: Self::NIL, b: Self::NIL }
            }

            fn child(link: $link) -> Option<usize> {
                (link != Self::NIL).then_some(link as usize)
            }

            /// Distances of every link, `child index - parent index`.
            pub fn reach(&self) -> Reach {
                Reach::from_deltas(self.nodes.iter().enumerate().flat_map(|(parent, node)| {
                    [node.a, node.b]
                        .into_iter()
                        .filter_map(Self::child)
                        .map(move |child| child as i64 - parent as i64)
                }))
            }
        }

        impl TreeView for $store {
            type Ref<'a> = usize;

            fn root(&self) -> Option<usize> {
                (!self.nodes.is_empty()).then_some(self.root)
            }

            fn payload(&self, r: usize) -> u32 {
                self.nodes[r].payload
            }

            fn a(&self, r: usize) -> Option<usize> {
                Self::child(self.nodes[r].a)
            }

            fn b(&self, r: usize) -> Option<usize> {
                Self::child(self.nodes[r].b)
            }
        }

        impl TreeBuild for $store {
            const NODE_BYTES: usize = size_of::<$node>();
            const LIMIT: Limit = Limit::None;

            fn empty(capacity: usize) -> Self {
                $store { nodes: Vec::with_capacity(capacity), root: 0 }
            }

            fn from_plan(plan: &Plan) -> Self {
                let link = |child: Option<u32>| child.map_or(Self::NIL, |i| i as $link);
                let nodes = plan
                    .nodes
                    .iter()
                    .map(|spec| $node { payload: spec.payload, a: link(spec.a), b: link(spec.b) })
                    .collect();
                $store { nodes, root: plan.root().unwrap_or(0) }
            }

            fn insert_bst(&mut self, key: u32) {
                if self.nodes.is_empty() {
                    self.nodes.push(Self::leaf(key));
                    self.root = 0;
                    return;
                }
                let mut at = self.root;
                loop {
                    let node = self.nodes[at];
                    if key == node.payload {
                        return;
                    }
                    let go_a = key < node.payload;
                    let next = if go_a { node.a } else { node.b };
                    if next == Self::NIL {
                        let new = self.nodes.len() as $link;
                        self.nodes.push(Self::leaf(key));
                        if go_a {
                            self.nodes[at].a = new;
                        } else {
                            self.nodes[at].b = new;
                        }
                        return;
                    }
                    at = next as usize;
                }
            }

            fn len(&self) -> usize {
                self.nodes.len()
            }
        }
    };
}
````

````rust
    ) => {
        /// One node: a little-endian payload and two narrow links, 1-byte aligned.
        #[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned, Clone, Copy)]
        #[repr(C)]
        pub struct $node {
            payload: U32,
            a: $link<$node, $w>,
            b: $link<$node, $w>,
        }

        $(#[$doc])*
        pub struct $store {
            arena: Arena<$node>,
            root: usize,
        }

        impl $store {
            fn link($owner: usize, $child: Option<usize>) -> $link<$node, $w> {
                $make.expect("reach checked by the workload")
            }

            fn leaf(key: u32) -> $node {
                $node { payload: U32::new(key), a: $link::NULL, b: $link::NULL }
            }
        }

        impl TreeView for $store {
            type Ref<'a> = Cursor<'a, $node>;

            fn root(&self) -> Option<Cursor<'_, $node>> {
                self.arena.cursor(self.root)
            }

            fn payload(&self, r: Cursor<'_, $node>) -> u32 {
                r.get().payload.get()
            }

            fn a<'a>(&'a self, r: Cursor<'a, $node>) -> Option<Cursor<'a, $node>> {
                r.follow(r.get().a)
            }

            fn b<'a>(&'a self, r: Cursor<'a, $node>) -> Option<Cursor<'a, $node>> {
                r.follow(r.get().b)
            }
        }

        impl TreeBuild for $store {
            const NODE_BYTES: usize = size_of::<$node>();
            const LIMIT: Limit = $limit;

            fn empty(capacity: usize) -> Self {
                $store { arena: Arena::with_capacity(capacity), root: 0 }
            }

            fn from_plan(plan: &Plan) -> Self {
                let mut arena = Arena::with_capacity(plan.nodes.len());
                for (owner, spec) in plan.nodes.iter().enumerate() {
                    arena.push($node {
                        payload: U32::new(spec.payload),
                        a: Self::link(owner, spec.a.map(|i| i as usize)),
                        b: Self::link(owner, spec.b.map(|i| i as usize)),
                    });
                }
                $store { arena, root: plan.root().unwrap_or(0) }
            }

            fn insert_bst(&mut self, key: u32) {
                if self.arena.is_empty() {
                    self.arena.push(Self::leaf(key));
                    self.root = 0;
                    return;
                }
                let mut at = self.root;
                loop {
                    let node = self.arena.as_slice()[at];
                    let at_key = node.payload.get();
                    if key == at_key {
                        return;
                    }
                    let go_a = key < at_key;
                    let link = if go_a { node.a } else { node.b };
                    match self.arena.follow(at, link) {
                        Some((next, _)) => at = next,
                        None => {
                            let new = self.arena.push(Self::leaf(key));
                            let link = Self::link(at, Some(new));
                            let parent = self.arena.get_mut(at).expect("the owner exists");
                            if go_a {
                                parent.a = link;
                            } else {
                                parent.b = link;
                            }
                            return;
                        }
                    }
                }
            }

            fn len(&self) -> usize {
                self.arena.len()
            }
        }
    };
}
````

````rust
/// Runs one variant: reports `Unreachable` when its links cannot represent the structure, and
/// otherwise times `build` and `traverse`.
pub(crate) fn run_variant<V: TreeBuild>(
    params: &Params,
    nodes: usize,
    reach: &Reach,
    unit: &'static str,
    build: impl FnMut() -> V,
    traverse: impl FnMut(&V) -> Pass,
) -> Result<Outcome, String> {
    if !V::LIMIT.admits(nodes, reach) {
        return Ok(Outcome::Unreachable(*reach));
    }
    Ok(Outcome::from_reps(
        run_reps(params, nodes as u64, build, traverse),
        V::NODE_BYTES,
        unit,
        Some(*reach),
    ))
}

/// A lookup pass: counts the probes that are found.
pub(crate) fn lookups<V: TreeView>(view: &V, probes: &[u32]) -> Pass {
    let hits = probes.iter().filter(|&&key| contains(view, key)).count() as u64;
    Pass {
        checksum: hits,
        units: probes.len() as u64,
    }
}
````

````rust
/// Nodes are allocated in insertion order, so parent and child are far apart: poor locality.
pub struct BstRandom;

impl Workload for BstRandom {
    fn name(&self) -> &'static str {
        "bst-random"
    }

    fn variants(&self) -> &'static [&'static str] {
        VARIANTS
    }

    fn max_n(&self) -> usize {
        1 << 22
    }

    fn run(&self, variant: &str, params: &Params) -> Result<Outcome, String> {
        let n = params.n;
        let mut rng = Rng::new(params.seed);
        let keys: Vec<u32> = (0..n).map(|_| rng.next_u32()).collect();
        let probes: Vec<u32> = (0..n)
            .map(|i| {
                if i % 2 == 0 {
                    keys[rng.below(n as u64) as usize]
                } else {
                    rng.next_u32()
                }
            })
            .collect();

        // The link distances do not depend on the representation, so measure them once on the
        // hand-written u32 variant and let each variant check them against its width.
        let reference = {
            let mut tree = PlainU32::empty(n);
            for &key in &keys {
                tree.insert_bst(key);
            }
            tree
        };
        let (reach, nodes) = (reference.reach(), reference.len());
        drop(reference);

        with_variant!(variant, V => run_variant::<V>(
            params,
            nodes,
            &reach,
            "lookup",
            || {
                let mut tree = V::empty(n);
                for &key in &keys {
                    tree.insert_bst(key);
                }
                tree
            },
            |tree| lookups(tree, &probes),
        ))
    }
}
````

````rust
//! `ast-bytes`: a bench-only prototype of a Goose-style byte layout, used for the layer-4 gate.
//!
//! The same expression tree as the `ast` workload is stored as variable-size records appended to
//! one `Vec<u8>` in creation order (children first). Links are LEB128 varints holding the
//! backward distance in bytes to the child's record, so small distances cost one byte. It is
//! not part of the library.

use crate::measure::{Params, Pass, run_reps};
use crate::plan::{CONST_MASK, OP_MUL, Plan};
use crate::workload::{Outcome, Workload};

const TAG_LEAF: u8 = 0;
const TAG_ADD: u8 = 1;
const TAG_NEG: u8 = 2;
const TAG_MUL: u8 = 3;

fn put_varint(out: &mut Vec<u8>, mut value: u64) {
    loop {
        let byte = (value & 0x7F) as u8;
        value >>= 7;
        if value == 0 {
            out.push(byte);
            return;
        }
        out.push(byte | 0x80);
    }
}

fn get_varint(bytes: &[u8], at: &mut usize) -> u64 {
    let mut value = 0u64;
    let mut shift = 0;
    loop {
        let byte = bytes[*at];
        *at += 1;
        value |= u64::from(byte & 0x7F) << shift;
        if byte & 0x80 == 0 {
            return value;
        }
        shift += 7;
    }
}

/// An expression tree stored as variable-size byte records.
pub struct ByteTree {
    bytes: Vec<u8>,
    root: usize,
    nodes: usize,
}

impl ByteTree {
    /// Encodes `plan`.
    pub fn from_plan(plan: &Plan) -> ByteTree {
        let mut bytes = Vec::new();
        let mut starts: Vec<usize> = Vec::with_capacity(plan.nodes.len());
        for spec in &plan.nodes {
            let here = bytes.len();
            starts.push(here);
            match (spec.a, spec.b) {
                (None, _) => {
                    bytes.push(TAG_LEAF);
                    bytes.extend_from_slice(&(spec.payload & CONST_MASK).to_le_bytes()[..3]);
                }
                (Some(a), None) => {
                    bytes.push(TAG_NEG);
                    put_varint(&mut bytes, (here - starts[a as usize]) as u64);
                }
                (Some(a), Some(b)) => {
                    bytes.push(if spec.payload >> 24 == OP_MUL {
                        TAG_MUL
                    } else {
                        TAG_ADD
                    });
                    put_varint(&mut bytes, (here - starts[a as usize]) as u64);
                    put_varint(&mut bytes, (here - starts[b as usize]) as u64);
                }
            }
        }
        bytes.shrink_to_fit();
        ByteTree {
            root: starts.last().copied().unwrap_or(0),
            nodes: plan.nodes.len(),
            bytes,
        }
    }

    /// Total size of the records in bytes.
    pub fn byte_len(&self) -> usize {
        self.bytes.len()
    }

    /// Evaluates the tree with explicit stacks. Returns the value and the number of records
    /// visited, with the same semantics as the `ast` workload.
    pub fn eval(&self) -> (u32, u64) {
        enum Step {
            Enter(usize),
            Combine(u8),
        }
        if self.nodes == 0 {
            return (0, 0);
        }
        let mut stack = vec![Step::Enter(self.root)];
        let mut values: Vec<u32> = Vec::new();
        let mut visits = 0u64;
        while let Some(step) = stack.pop() {
            match step {
                Step::Enter(offset) => {
                    visits += 1;
                    let tag = self.bytes[offset];
                    let mut at = offset + 1;
                    match tag {
                        TAG_LEAF => values.push(u32::from_le_bytes([
                            self.bytes[at],
                            self.bytes[at + 1],
                            self.bytes[at + 2],
                            0,
                        ])),
                        TAG_NEG => {
                            let a = offset - get_varint(&self.bytes, &mut at) as usize;
                            stack.push(Step::Combine(tag));
                            stack.push(Step::Enter(a));
                        }
                        _ => {
                            let a = offset - get_varint(&self.bytes, &mut at) as usize;
                            let b = offset - get_varint(&self.bytes, &mut at) as usize;
                            stack.push(Step::Combine(tag));
                            stack.push(Step::Enter(b));
                            stack.push(Step::Enter(a));
                        }
                    }
                }
                Step::Combine(TAG_NEG) => {
                    let x = values.pop().expect("operand");
                    values.push(x.wrapping_neg());
                }
                Step::Combine(tag) => {
                    let y = values.pop().expect("second operand");
                    let x = values.pop().expect("first operand");
                    values.push(if tag == TAG_MUL {
                        x.wrapping_mul(y)
                    } else {
                        x.wrapping_add(y)
                    });
                }
            }
        }
        (values.pop().unwrap_or(0), visits)
    }
}
````

````rust
//! Graph workloads: `graph-csr`, `graph-linked-seq` and `graph-linked-shuf`.
//!
//! All three run a breadth-first search from vertex 0 over the same random graph (out-degree 1 to
//! 7, average 4, so about `4 * n` edges) and differ only in how adjacency is stored. `n` is the
//! number of vertices; heap and build figures are normalised per vertex.

use rustlink::{Abs, Arena, OptAbs, OptRel, Region, Width};
use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};

use crate::measure::{Params, Pass, run_reps};
use crate::rng::Rng;
use crate::workload::{Limit, Outcome, Reach, Workload};

/// The workloads this module provides.

/// Marker type for vertex ids stored as typed links.
pub struct Vertex;

/// A random graph in flat form: per-vertex out-degrees and all targets in vertex order.
pub struct Graph {
    /// Out-degree of each vertex.
    pub degrees: Vec<u8>,
    /// Every edge target, grouped by source vertex.
    pub targets: Vec<u32>,
}

impl Graph {
    /// Generates a graph with `vertices` vertices. Targets may repeat and may be self loops.
    pub fn generate(vertices: usize, seed: u64) -> Graph {
        let mut rng = Rng::new(seed);
        let mut degrees = Vec::with_capacity(vertices);
        let mut targets = Vec::with_capacity(vertices * 4);
        for _ in 0..vertices {
            let degree = 1 + rng.below(7) as u8;
            degrees.push(degree);
            for _ in 0..degree {
                targets.push(rng.below(vertices as u64) as u32);
            }
        }
        Graph { degrees, targets }
    }

    /// Number of vertices.
    pub fn vertices(&self) -> usize {
        self.degrees.len()
    }

    /// Number of edges.
    pub fn edges(&self) -> usize {
        self.targets.len()
    }
}

/// Neighbour enumeration, the only thing BFS needs from a representation.
trait Adjacency {
    fn for_each_neighbor(&self, vertex: usize, f: impl FnMut(usize));
}

fn bfs<A: Adjacency>(adjacency: &A, vertices: usize) -> Pass {
    if vertices == 0 {
        return Pass {
            checksum: 0,
            units: 0,
        };
    }
    let mut dist = vec![u32::MAX; vertices];
    let mut queue: Vec<u32> = Vec::with_capacity(vertices);
    dist[0] = 0;
    queue.push(0);
    let (mut head, mut edges) = (0usize, 0u64);
    while head < queue.len() {
        let u = queue[head] as usize;
        head += 1;
        let next = dist[u] + 1;
        adjacency.for_each_neighbor(u, |w| {
            edges += 1;
            if dist[w] == u32::MAX {
                dist[w] = next;
                queue.push(w as u32);
            }
        });
    }
    let checksum = dist
        .iter()
        .filter(|&&d| d != u32::MAX)
        .fold(0u64, |acc, &d| {
            acc.wrapping_add(u64::from(d)).wrapping_add(1)
        });
    Pass {
        checksum,
        units: edges,
    }
}

/// Compressed sparse row storage.
trait CsrStore: Adjacency + Sized {
    /// Bytes of one edge entry.
    const ENTRY_BYTES: usize;
    fn build(graph: &Graph) -> Self;
}

fn offsets_of(graph: &Graph) -> impl Iterator<Item = usize> + '_ {
    std::iter::once(0).chain(graph.degrees.iter().scan(0usize, |sum, &degree| {
        *sum += usize::from(degree);
        Some(*sum)
    }))
}

struct CsrUsize {
    offsets: Vec<usize>,
    targets: Vec<usize>,
}

impl Adjacency for CsrUsize {
    fn for_each_neighbor(&self, vertex: usize, mut f: impl FnMut(usize)) {
        for &target in &self.targets[self.offsets[vertex]..self.offsets[vertex + 1]] {
            f(target);
        }
    }
}

impl CsrStore for CsrUsize {
    const ENTRY_BYTES: usize = size_of::<usize>();

    fn build(graph: &Graph) -> Self {
        CsrUsize {
            offsets: offsets_of(graph).collect(),
            targets: graph.targets.iter().map(|&t| t as usize).collect(),
        }
    }
}

struct CsrU32 {
    offsets: Vec<u32>,
    targets: Vec<u32>,
}

impl Adjacency for CsrU32 {
    fn for_each_neighbor(&self, vertex: usize, mut f: impl FnMut(usize)) {
        let range = self.offsets[vertex] as usize..self.offsets[vertex + 1] as usize;
        for &target in &self.targets[range] {
            f(target as usize);
        }
    }
}

impl CsrStore for CsrU32 {
    const ENTRY_BYTES: usize = size_of::<u32>();

    fn build(graph: &Graph) -> Self {
        CsrU32 {
            offsets: offsets_of(graph).map(|o| o as u32).collect(),
            targets: graph.targets.clone(),
        }
    }
}

/// Control: typed vertex ids must cost the same as plain `u32`.
struct CsrAbs32 {
    offsets: Vec<u32>,
    targets: Vec<Abs<Vertex, u32>>,
}

impl Adjacency for CsrAbs32 {
    fn for_each_neighbor(&self, vertex: usize, mut f: impl FnMut(usize)) {
        let range = self.offsets[vertex] as usize..self.offsets[vertex + 1] as usize;
        for target in &self.targets[range] {
            f(target.index());
        }
    }
}

impl CsrStore for CsrAbs32 {
    const ENTRY_BYTES: usize = size_of::<Abs<Vertex, u32>>();

    fn build(graph: &Graph) -> Self {
        CsrAbs32 {
            offsets: offsets_of(graph).map(|o| o as u32).collect(),
            targets: graph
                .targets
                .iter()
                .map(|&t| Abs::new(t as usize).expect("vertex ids fit in u32"))
                .collect(),
        }
    }
}

fn run_csr<S: CsrStore>(params: &Params, graph: &Graph) -> Result<Outcome, String> {
    let vertices = graph.vertices();
    Ok(Outcome::from_reps(
        run_reps(
            params,
            vertices as u64,
            || S::build(graph),
            |store| bfs(store, vertices),
        ),
        S::ENTRY_BYTES,
        "edge",
        None,
    ))
}

/// The linked edge lists of a graph, independent of link representation. Edges live in "slots";
/// every vertex's edges form a chain through `next`.
pub struct EdgePlan {
    /// First slot of each vertex's chain.
    pub heads: Vec<Option<u32>>,
    /// `(target vertex, next slot in the chain)` for every slot.
    pub edges: Vec<(u32, Option<u32>)>,
}

impl EdgePlan {
    /// Lays the graph's edges out in slots. Sequential: a vertex's edges are consecutive slots,
    /// so every `next` is the following slot. Shuffled: slots are a random permutation, so
    /// `next` distances are random.
    pub fn new(graph: &Graph, shuffled: bool, seed: u64) -> EdgePlan {
        let slot_count = graph.edges();
        let mut slot_of: Vec<u32> = (0..slot_count as u32).collect();
        if shuffled {
            Rng::new(seed ^ 0xD6E8_FEB8_6659_FD93).shuffle(&mut slot_of);
        }
        let mut heads = vec![None; graph.vertices()];
        let mut edges = vec![(0u32, None); slot_count];
        let mut logical = 0usize;
        for (vertex, &degree) in graph.degrees.iter().enumerate() {
            let mut previous: Option<usize> = None;
            for k in 0..usize::from(degree) {
                let slot = slot_of[logical + k] as usize;
                edges[slot].0 = graph.targets[logical + k];
                match previous {
                    None => heads[vertex] = Some(slot as u32),
                    Some(p) => edges[p].1 = Some(slot as u32),
                }
                previous = Some(slot);
            }
            logical += usize::from(degree);
        }
        EdgePlan { heads, edges }
    }

    /// Distances `next slot - slot` of every chain link.
    pub fn reach(&self) -> Reach {
        Reach::from_deltas(
            self.edges
                .iter()
                .enumerate()
                .filter_map(|(slot, (_, next))| next.map(|n| i64::from(n) - slot as i64)),
        )
    }
}

/// Per-vertex singly linked edge lists in one representation.
trait LinkedStore: Adjacency + Sized {
    /// `size_of` one edge node.
    const EDGE_BYTES: usize;
    /// What the `next` links can address (counted in edges).
    const LIMIT: Limit;
    fn build(plan: &EdgePlan) -> Self;
}

struct BoxEdge {
    to: u32,
    next: Option<Box<BoxEdge>>,
}

struct LinkedBox {
    heads: Vec<Option<Box<BoxEdge>>>,
}

impl Drop for LinkedBox {
    /// Drops chains iteratively so a long chain cannot overflow the call stack.
    fn drop(&mut self) {
        for head in self.heads.drain(..) {
            let mut current = head;
            while let Some(mut edge) = current {
                current = edge.next.take();
            }
        }
    }
}

impl Adjacency for LinkedBox {
    fn for_each_neighbor(&self, vertex: usize, mut f: impl FnMut(usize)) {
        let mut edge = self.heads[vertex].as_deref();
        while let Some(e) = edge {
            f(e.to as usize);
            edge = e.next.as_deref();
        }
    }
}

impl LinkedStore for LinkedBox {
    const EDGE_BYTES: usize = size_of::<BoxEdge>();
    const LIMIT: Limit = Limit::None;

    fn build(plan: &EdgePlan) -> Self {
        let mut chain: Vec<u32> = Vec::new();
        let heads = plan
            .heads
            .iter()
            .map(|&head| {
                chain.clear();
                let mut current = head;
                while let Some(slot) = current {
                    chain.push(slot);
                    current = plan.edges[slot as usize].1;
                }
                let mut next = None;
                for &slot in chain.iter().rev() {
                    next = Some(Box::new(BoxEdge {
                        to: plan.edges[slot as usize].0,
                        next,
                    }));
                }
                next
            })
            .collect();
        LinkedBox { heads }
    }
}

macro_rules! linked_narrow {
    (
        $(#[$doc:meta])* $store:ident, $edge:ident, $link:ident, $w:ty,
        $limit:expr, |$owner:ident, $next:ident| $make:expr
    ) => {
        /// One edge: a typed target vertex and a narrow link to the next edge of the chain.
        #[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned, Clone, Copy)]
        #[repr(C)]
        struct $edge {
            to: Abs<Vertex, u32>,
            next: $link<$edge, $w>,
        }

        $(#[$doc])*
        struct $store {
            heads: Vec<OptAbs<$edge, u32>>,
            edges: Arena<$edge>,
        }

        impl Adjacency for $store {
            fn for_each_neighbor(&self, vertex: usize, mut f: impl FnMut(usize)) {
                let mut cursor = self.heads[vertex].get().and_then(|slot| self.edges.cursor(slot));
                while let Some(at) = cursor {
                    let edge = at.get();
                    f(edge.to.index());
                    cursor = at.follow(edge.next);
                }
            }
        }

        impl LinkedStore for $store {
            const EDGE_BYTES: usize = size_of::<$edge>();
            const LIMIT: Limit = $limit;

            fn build(plan: &EdgePlan) -> Self {
                let mut edges = Arena::with_capacity(plan.edges.len());
                for (slot, &(to, next)) in plan.edges.iter().enumerate() {
                    let ($owner, $next) = (slot, next.map(|s| s as usize));
                    edges.push($edge {
                        to: Abs::new(to as usize).expect("vertex ids fit in u32"),
                        next: $make.expect("reach checked by the workload"),
                    });
                }
                let heads = plan
                    .heads
                    .iter()
                    .map(|h| OptAbs::new(h.map(|s| s as usize)).expect("edge slots fit in u32"))
                    .collect();
                $store { heads, edges }
            }
        }
    };
}

fn run_linked<S: LinkedStore>(
    params: &Params,
    vertices: usize,
    plan: &EdgePlan,
    reach: &Reach,

        return Ok(Outcome::Unreachable(*reach));

        run_reps(
            params,

            || S::build(plan),
            |store| bfs(store, vertices),
        ),
        S::EDGE_BYTES,
        "edge",
        Some(*reach),
    ))
}

    /// BFS written directly over the flat graph, independent of every representation.
    fn reference(graph: &Graph) -> Pass {
        let n = graph.vertices();
        let mut starts = vec![0usize; n + 1];
        for v in 0..n {
            starts[v + 1] = starts[v] + usize::from(graph.degrees[v]);
        }
        let mut dist = vec![u32::MAX; n];
        let mut queue = std::collections::VecDeque::from([0usize]);
        dist[0] = 0;
        let mut edges = 0u64;
        while let Some(u) = queue.pop_front() {
            for &t in &graph.targets[starts[u]..starts[u + 1]] {
                edges += 1;
                if dist[t as usize] == u32::MAX {
                    dist[t as usize] = dist[u] + 1;
                    queue.push_back(t as usize);
                }
            }
        }
        let checksum = dist
            .iter()
            .filter(|&&d| d != u32::MAX)
            .fold(0u64, |acc, &d| {
                acc.wrapping_add(u64::from(d)).wrapping_add(1)
            });
        Pass {
            checksum,
            units: edges,
        }
    }

        for (slot, (_, next)) in seq.edges.iter().enumerate() {
            if let Some(n) = next {

            }
````

````rust
//! Process-level measurements read from `/proc`.

use std::fs;
use std::io;

/// Resource usage of the current process.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct ProcStats {
    /// Peak resident set size in KiB (`VmHWM`).
    pub peak_rss_kib: u64,
    /// Minor page faults.
    pub minor_faults: u64,
    /// Major page faults.
    pub major_faults: u64,
}

/// The value of `key` in `/proc`-style `Key:   1234 kB` text, in the unit the file uses.
pub fn parse_status_kib(text: &str, key: &str) -> Option<u64> {
    text.lines().find_map(|line| {
        let rest = line.strip_prefix(key)?.strip_prefix(':')?;
        rest.split_whitespace().next()?.parse().ok()
    })
}

/// `(minor, major)` page faults from the text of `/proc/<pid>/stat`.
///
/// The command name is in parentheses and may itself contain spaces and parentheses, so fields
/// are counted after the last `)`: `state ppid pgrp session tty_nr tpgid flags minflt cminflt
/// majflt ...`.
pub fn parse_stat_faults(text: &str) -> Option<(u64, u64)> {
    let after_comm = &text[text.rfind(')')? + 1..];
    let fields: Vec<&str> = after_comm.split_whitespace().collect();
    Some((fields.get(7)?.parse().ok()?, fields.get(9)?.parse().ok()?))
}

/// Reads the current process's peak RSS and page faults.
pub fn read_self() -> io::Result<ProcStats> {
    let status = fs::read_to_string("/proc/self/status")?;
    let stat = fs::read_to_string("/proc/self/stat")?;
    let peak_rss_kib = parse_status_kib(&status, "VmHWM")
        .ok_or_else(|| io::Error::other("VmHWM missing from /proc/self/status"))?;
    let (minor_faults, major_faults) =
        parse_stat_faults(&stat).ok_or_else(|| io::Error::other("cannot parse /proc/self/stat"))?;
    Ok(ProcStats {
        peak_rss_kib,
        minor_faults,
        major_faults,
    })
}

/// `MemAvailable` in KiB, if `/proc/meminfo` reports it.
pub fn mem_available_kib() -> Option<u64> {
    parse_status_kib(&fs::read_to_string("/proc/meminfo").ok()?, "MemAvailable")
}
````

````rust
//! Markdown rendering of benchmark results.

use std::collections::BTreeSet;
use std::fmt::Write as _;
use std::fs;
use std::process::Command;

use crate::measure::Measurement;
use crate::proc::mem_available_kib;

/// Machine description recorded in the report header.
#[derive(Clone, Debug, PartialEq, Default)]
pub struct MachineInfo {
    /// CPU model name.
    pub cpu_model: String,
    /// The CPU the benchmark processes were pinned to.
    pub pinned_cpu: usize,
    /// Cache levels of the pinned CPU, e.g. `L1d 48K`.
    pub caches: Vec<String>,
    /// Kernel release.
    pub kernel: String,
    /// `rustc --version`.
    pub rustc: String,
    /// Short git revision of the checkout.
    pub git_rev: String,
    /// `MemAvailable` when the report was made.
    pub mem_available_kib: u64,
}

impl MachineInfo {
    /// Gathers the description of this machine. Best effort: missing facts stay empty.
    pub fn collect(pinned_cpu: usize) -> MachineInfo {
        let git_rev = command_output("git", &["rev-parse", "--short", "HEAD"]);
        MachineInfo {
            cpu_model: cpu_model(),
            pinned_cpu,
            caches: caches(pinned_cpu),
            kernel: command_output("uname", &["-r"]),
            rustc: command_output("rustc", &["--version"]),
            git_rev: if git_rev.is_empty() {
                "unknown".to_owned()
            } else {
                git_rev
            },
            mem_available_kib: mem_available_kib().unwrap_or(0),
        }
    }
}

fn command_output(program: &str, args: &[&str]) -> String {
    Command::new(program)
        .args(args)
        .output()
        .ok()
        .filter(|output| output.status.success())
        .map(|output| String::from_utf8_lossy(&output.stdout).trim().to_owned())
        .unwrap_or_default()
}

fn cpu_model() -> String {
    fs::read_to_string("/proc/cpuinfo")
        .ok()
        .and_then(|text| {
            text.lines().find_map(|line| {
                let rest = line.strip_prefix("model name")?;
                Some(rest.split_once(':')?.1.trim().to_owned())
            })
        })
        .unwrap_or_else(|| "unknown".to_owned())
}

fn caches(cpu: usize) -> Vec<String> {
    let mut levels: Vec<(u32, String)> = Vec::new();
    for index in 0..8 {
        let dir = format!("/sys/devices/system/cpu/cpu{cpu}/cache/index{index}");
        let read = |name: &str| {
            fs::read_to_string(format!("{dir}/{name}"))
                .ok()
                .map(|s| s.trim().to_owned())
        };
        let (Some(level), Some(kind), Some(size)) = (read("level"), read("type"), read("size"))
        else {
            continue;
        };
        if kind == "Instruction" {
            continue;
        }
        let suffix = if kind == "Data" { "d" } else { "" };
        levels.push((
            level.parse().unwrap_or(0),
            format!("L{level}{suffix} {size}"),
        ));
    }
    levels.sort();
    levels.into_iter().map(|(_, text)| text).collect()
}

fn unique_in_order<'a>(items: impl Iterator<Item = &'a str>) -> Vec<&'a str> {
    let mut seen = BTreeSet::new();
    items.filter(|item| seen.insert(*item)).collect()
}

fn size_label(n: u64) -> String {
    if n.is_power_of_two() {
        format!("2^{}", n.trailing_zeros())
    } else {
        n.to_string()
    }
}

/// Renders the whole report as Markdown. Pure: no I/O.
///
/// When a cell appears more than once the last measurement wins.
pub fn render(measurements: &[Measurement], info: &MachineInfo) -> String {
    let mut out = String::from("# rustlink benchmark results\n\n");
    let _ = writeln!(
        out,
        "- CPU: {} (processes pinned to cpu{})",
        info.cpu_model, info.pinned_cpu
    );
    if !info.caches.is_empty() {
        let _ = writeln!(
            out,
            "- Caches of the pinned CPU: {}",
            info.caches.join(", ")
        );
    }
    let _ = writeln!(out, "- Kernel: {}", info.kernel);
    let _ = writeln!(out, "- Compiler: {}", info.rustc);
    let _ = writeln!(out, "- Git revision: {}", info.git_rev);
    let _ = writeln!(
        out,
        "- MemAvailable: {:.1} GiB\n",
        info.mem_available_kib as f64 / 1_048_576.0
    );

    for workload in unique_in_order(measurements.iter().map(|m| m.workload.as_str())) {
        let cells: Vec<&Measurement> = measurements
            .iter()
            .filter(|m| m.workload == workload)
            .collect();
        render_workload(&mut out, workload, &cells);
    }
    render_gate(&mut out, measurements);
    out
}

fn render_workload(out: &mut String, workload: &str, cells: &[&Measurement]) {
    let variants = unique_in_order(cells.iter().map(|m| m.variant.as_str()));
    let sizes: Vec<u64> = cells
        .iter()
        .map(|m| m.n)
        .collect::<BTreeSet<_>>()
        .into_iter()
        .collect();
    let unit = cells
        .iter()
        .find(|m| m.status == "done")
        .map_or("unit", |m| m.unit.as_str());
    let _ = writeln!(out, "## {workload}\n");

    let mut table = |title: &str, value: &dyn Fn(&Measurement) -> String| {
        write_table(out, title, &variants, &sizes, cells, value);
    };
    table(&format!("Traverse (ns per {unit}, median ± MAD)"), &|m| {
        format!("{:.1} ± {:.1}", m.traverse_ns_median, m.traverse_ns_mad)
    });
    table("Build (ns per node, median ± MAD)", &|m| {
        format!("{:.1} ± {:.1}", m.build_ns_median, m.build_ns_mad)
    });
    table("Heap (bytes per node)", &|m| {
        format!("{:.1}", m.heap_bytes_per_node)
    });
    table("Peak RSS (MiB)", &|m| {
        format!("{:.1}", m.peak_rss_kib as f64 / 1024.0)
    });
    table("Node size (bytes)", &|m| m.node_bytes.to_string());

    let notes: Vec<String> = cells
        .iter()
        .filter(|m| m.status != "done")
        .map(|m| {
            let note = if m.note.is_empty() {
                m.status.as_str()
            } else {
                m.note.as_str()
            };
            format!("- `{}` at {}: {note}", m.variant, size_label(m.n))
        })
        .collect();
    if !notes.is_empty() {
        let _ = writeln!(out, "### Notes\n");
        for note in notes {
            let _ = writeln!(out, "{note}");
        }
        out.push('\n');
    }
}

fn write_table(
    out: &mut String,
    title: &str,
    variants: &[&str],
    sizes: &[u64],
    cells: &[&Measurement],
    value: &dyn Fn(&Measurement) -> String,
) {
    let _ = writeln!(out, "### {title}\n");
    let header: Vec<String> = sizes.iter().map(|&n| size_label(n)).collect();
    let _ = writeln!(out, "| variant | {} |", header.join(" | "));
    let _ = writeln!(out, "|---|{}|", vec!["---:"; sizes.len()].join("|"));
    for variant in variants {
        let row: Vec<String> = sizes
            .iter()
            .map(|&n| {
                match cells
                    .iter()
                    .rev()
                    .find(|m| m.variant == *variant && m.n == n)
                {
                    None => "-".to_owned(),
                    Some(m) => match m.status.as_str() {
                        "done" => value(m),
                        "unreachable" => "n/a".to_owned(),
                        "skipped" => "skip".to_owned(),
                        _ => "fail".to_owned(),
                    },
                }
            })
            .collect();
        let _ = writeln!(out, "| {variant} | {} |", row.join(" | "));
    }
    out.push('\n');
}

fn render_gate(out: &mut String, measurements: &[Measurement]) {
    let _ = writeln!(out, "## Layer-4 gate\n");
    let _ = writeln!(
        out,
        "Rule: proceed to layer 4 only if `ast-bytes` uses at least 1.5x less heap than the best \
         layer-2 variant (`abs*` or `rel*`, lowest heap bytes per node) at no more than 1.1x its \
         traversal time, at N >= 2^20.\n"
    );
    let last_done = |workload: &str, variant_ok: &dyn Fn(&str) -> bool, n: u64| {
        measurements.iter().rev().find(|m| {
            m.workload == workload && m.n == n && m.status == "done" && variant_ok(&m.variant)
        })
    };
    let sizes: BTreeSet<u64> = measurements
        .iter()
        .filter(|m| m.workload == "ast-bytes" && m.status == "done" && m.n >= 1 << 20)
        .map(|m| m.n)
        .collect();

    let mut rows = Vec::new();
    for n in sizes {
        let Some(bytes) = last_done("ast-bytes", &|_| true, n) else {
            continue;
        };
        let candidates: Vec<&Measurement> = measurements
            .iter()
            .filter(|m| {
                m.workload == "ast"
                    && m.n == n
                    && m.status == "done"
                    && (m.variant.starts_with("abs") || m.variant.starts_with("rel"))
            })
            .collect();
        let Some(best) = candidates
            .iter()
            .min_by(|a, b| a.heap_bytes_per_node.total_cmp(&b.heap_bytes_per_node))
        else {
            continue;
        };
        let memory_ratio = if bytes.heap_bytes_per_node > 0.0 {
            best.heap_bytes_per_node / bytes.heap_bytes_per_node
        } else {
            0.0
        };
        let time_ratio = bytes.traverse_ns_median / best.traverse_ns_median;
        let verdict = if memory_ratio >= 1.5 && time_ratio <= 1.1 {
            "pass"
        } else {
            "fail"
        };
        rows.push(format!(
            "| {} | {} | {:.1} | {:.1} | {:.2} | {:.1} | {:.1} | {:.2} | {verdict} |",
            size_label(n),
            best.variant,
            best.heap_bytes_per_node,
            bytes.heap_bytes_per_node,
            memory_ratio,
            best.traverse_ns_median,
            bytes.traverse_ns_median,
            time_ratio,
        ));
    }

    if rows.is_empty() {
        let _ = writeln!(
            out,
            "No data for the gate (needs ast and ast-bytes at N >= 2^20)."
        );
        return;
    }
    let _ = writeln!(
        out,
        "| N | best L2 variant | its heap B/node | ast-bytes heap B/node | memory ratio | its traverse ns | \
         ast-bytes traverse ns | time ratio | verdict |"
    );
    let _ = writeln!(out, "|---|---|---:|---:|---:|---:|---:|---:|---|");
    for row in rows {
        let _ = writeln!(out, "{row}");
    }
}
````

//! `rlb`: runs one benchmark cell in a fresh process and prints one line of JSON.

//! ```text
//! rlb list
//! rlb run --workload W --variant V --n N [--reps R] [--seed S] [--budget-secs B]

use std::collections::HashMap;
use std::process::ExitCode;

use rustlink_bench::alloc::Counting;
use rustlink_bench::measure::{Measurement, Params};
use rustlink_bench::proc;

#[global_allocator]
static ALLOC: Counting = Counting;

const USAGE: &str = "usage:\n  rlb list\n  rlb run --workload W --variant V --n N [--reps R] [--seed S] [--budget-secs B]";

#[derive(Debug, PartialEq)]
struct RunArgs {
    workload: String,
    variant: String,
    params: Params,
}

fn parse_flags<'a>(
    args: &'a [String],
    known: &[&str],
) -> Result<HashMap<&'a str, &'a str>, String> {
    let mut flags = HashMap::new();
    let mut iter = args.iter();
    while let Some(flag) = iter.next() {
        let name = flag
            .strip_prefix("--")
            .ok_or_else(|| format!("unexpected argument `{flag}`"))?;
        if !known.contains(&name) {
            return Err(format!("unknown flag `--{name}`"));
        }
        let value = iter
            .next()
            .ok_or_else(|| format!("flag `--{name}` needs a value"))?;
        flags.insert(name, value.as_str());
    }
    Ok(flags)
}

fn number<T: std::str::FromStr>(
    flags: &HashMap<&str, &str>,
    name: &str,
) -> Result<Option<T>, String> {
    flags
        .get(name)
        .map(|value| {
            value
                .parse::<T>()
                .map_err(|_| format!("`--{name}` expects a number, got `{value}`"))
        })
        .transpose()
}

fn parse_run(args: &[String]) -> Result<RunArgs, String> {
    let flags = parse_flags(
        args,
        &["workload", "variant", "n", "reps", "seed", "budget-secs"],
    )?;
    let text = |name: &str| {
        flags
            .get(name)
            .map(|value| (*value).to_owned())
            .ok_or_else(|| format!("missing `--{name}`"))
    };
    let n = number::<usize>(&flags, "n")?.ok_or("missing `--n`")?;
    let mut params = Params::new(n);
    if let Some(reps) = number::<usize>(&flags, "reps")? {
        if reps < 2 {
            return Err("`--reps` must be at least 2 (one warm-up, one measured)".to_owned());
        }
        params.reps = reps;
    }
    if let Some(seed) = number::<u64>(&flags, "seed")? {
        params.seed = seed;
    }
    if let Some(secs) = number::<u64>(&flags, "budget-secs")? {
        params.budget = Duration::from_secs(secs);
    }
    Ok(RunArgs {
        workload: text("workload")?,
        variant: text("variant")?,
        params,
    })
}

fn list() {
    for workload in registry::all() {
        println!(
            "{}\t{}\t{}\t{}",
            workload.name(),
            workload.max_n(),
            workload.footprint_per_n(),
            workload.variants().join(",")
        );
    }
}

fn run_cell(args: &[String]) -> Result<(), String> {
    let RunArgs {
        workload: name,
        variant,
        params,
    } = parse_run(args)?;
    let workload = registry::find(&name).ok_or_else(|| format!("unknown workload `{name}`"))?;
    if !workload.variants().contains(&variant.as_str()) {
        return Err(format!("workload `{name}` has no variant `{variant}`"));
    }
    let outcome = if params.n > workload.max_n() {
        Outcome::Skipped("n exceeds the workload's max_n".to_owned())
    } else {
        workload.run(&variant, &params)?
    };
    let mut measurement = Measurement::from_outcome(&name, &variant, &params, &outcome);
    let stats = proc::read_self().map_err(|e| format!("cannot read /proc: {e}"))?;
    measurement.peak_rss_kib = stats.peak_rss_kib;
    measurement.minor_faults = stats.minor_faults;
    measurement.major_faults = stats.major_faults;
    println!("{}", measurement.to_json());
    Ok(())
}

fn run(args: &[String]) -> Result<(), String> {
    match args.split_first() {
        Some((command, _)) if command == "list" => {
            list();
            Ok(())
        }
        Some((command, rest)) if command == "run" => run_cell(rest),
        _ => Err(USAGE.to_owned()),
    }
}

fn main() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    match run(&args) {
        Ok(()) => ExitCode::SUCCESS,
        Err(message) => {
            eprintln!("rlb: {message}");
            ExitCode::from(2)
        }
    }
}

//! `sweep`: runs the whole benchmark matrix, one pinned `rlb` process per cell, appends every
//! measurement to a JSONL file and renders the Markdown report.
//!
//! ```text
//! sweep [--out bench/results.jsonl] [--md bench/results.md] [--workloads a,b] [--variants x,y]
//!       [--sizes 10,12,...] [--big] [--reps 6] [--seed 1] [--budget-secs 120] [--cpu N]

use std::fs::{self, OpenOptions};
use std::io::Write as _;
use std::path::{Path, PathBuf};
use std::process::{Command, ExitCode};

use rustlink_bench::measure::Measurement;

const DEFAULT_EXPONENTS: [u32; 8] = [10, 12, 14, 16, 18, 20, 22, 24];
const USAGE: &str = "usage: sweep [--out FILE] [--md FILE] [--workloads a,b] [--variants x,y] \
[--sizes 10,12,...] [--big] [--reps N] [--seed N] [--budget-secs N] [--cpu N] [--dry-run] [--report-only]";

#[derive(Clone, Debug, PartialEq)]
struct Options {
    out: PathBuf,
    md: PathBuf,
    workloads: Option<Vec<String>>,
    variants: Option<Vec<String>>,
    exponents: Vec<u32>,
    reps: usize,
    seed: u64,
    budget_secs: u64,
    cpu: Option<usize>,
    dry_run: bool,
    report_only: bool,
}

impl Default for Options {
    fn default() -> Self {
        Options {
            out: PathBuf::from("bench/results.jsonl"),
            md: PathBuf::from("bench/results.md"),
            workloads: None,
            variants: None,
            exponents: DEFAULT_EXPONENTS.to_vec(),
            reps: 6,
            seed: 1,
            budget_secs: 120,
            cpu: None,
            dry_run: false,
            report_only: false,
        }

fn parse_list(text: &str) -> Vec<String> {
    text.split(',')
        .map(|item| item.trim().to_owned())
        .filter(|item| !item.is_empty())
        .collect()
}

fn parse_number<T: std::str::FromStr>(flag: &str, text: &str) -> Result<T, String> {
    text.parse()
        .map_err(|_| format!("`{flag}` expects a number, got `{text}`"))
}

/// Size exponents: `--sizes` or the default list, plus 26 with `--big`.
fn parse_sizes(arg: Option<&str>, big: bool) -> Result<Vec<u32>, String> {
    let mut exponents: Vec<u32> = match arg {
        Some(text) => parse_list(text)
            .iter()
            .map(|item| parse_number::<u32>("--sizes", item))
            .collect::<Result<_, _>>()?,
        None => DEFAULT_EXPONENTS.to_vec(),
    };
    if let Some(bad) = exponents.iter().find(|&&e| e > 40) {
        return Err(format!("size exponent {bad} is out of range (at most 40)"));
    }
    if big && !exponents.contains(&26) {
        exponents.push(26);
    }
    Ok(exponents)
}

fn parse_options(args: &[String]) -> Result<Options, String> {
    let mut options = Options::default();
    let (mut sizes, mut big) = (None, false);
    let mut iter = args.iter();
    while let Some(flag) = iter.next() {
        let mut value = |flag: &str| {
            iter.next()
                .cloned()
                .ok_or_else(|| format!("`{flag}` needs a value"))
        };
        match flag.as_str() {
            "--big" => big = true,
            "--dry-run" => options.dry_run = true,
            "--report-only" => options.report_only = true,
            "--out" => options.out = PathBuf::from(value(flag)?),
            "--md" => options.md = PathBuf::from(value(flag)?),
            "--workloads" => options.workloads = Some(parse_list(&value(flag)?)),
            "--variants" => options.variants = Some(parse_list(&value(flag)?)),
            "--sizes" => sizes = Some(value(flag)?),
            "--reps" => options.reps = parse_number(flag, &value(flag)?)?,
            "--seed" => options.seed = parse_number(flag, &value(flag)?)?,
            "--budget-secs" => options.budget_secs = parse_number(flag, &value(flag)?)?,
            "--cpu" => options.cpu = Some(parse_number(flag, &value(flag)?)?),
            other => return Err(format!("unknown argument `{other}`\n{USAGE}")),
        }
    }
    if options.reps < 2 {
        return Err("`--reps` must be at least 2 (one warm-up, one measured)".to_owned());
    }
    options.exponents = parse_sizes(sizes.as_deref(), big)?;
    Ok(options)
}

/// The cells to run, and the cells skipped up front because they would not fit in memory.
/// Sizes above a workload's `max_n` are left out entirely.
fn plan_cells(
    infos: &[WorkloadInfo],
    options: &Options,
    available_kib: Option<u64>,
) -> (Vec<Cell>, Vec<Measurement>) {
    let (mut cells, mut skips) = (Vec::new(), Vec::new());
    for info in infos {
        if options
            .workloads
            .as_ref()
            .is_some_and(|only| !only.contains(&info.name))
        {
            continue;
        }
        for variant in &info.variants {
            if options
                .variants
                .as_ref()
                .is_some_and(|only| !only.contains(variant))
            {
                continue;
            }
            for &exponent in &options.exponents {
                let n = 1usize << exponent;
                if n > info.max_n {
                    continue;
                }
                let cell = Cell {
                    workload: info.name.clone(),
                    variant: variant.clone(),
                    exponent,
                };
                if let Some(available) = available_kib {
                    let needed = (n as u64).saturating_mul(info.footprint_per_n as u64) / 1024;
                    if needed > available / 2 {
                        let note = format!(
                            "estimated footprint {needed} KiB exceeds half of MemAvailable ({available} KiB)"
                        );
                        skips.push(skipped(&cell, options, note));
                        continue;
                    }
                }
                cells.push(cell);
            }
        }
    }
    (cells, skips)
}

fn shuffle_cells(cells: &mut [Cell], seed: u64) {
    Rng::new(seed).shuffle(cells);
}

/// The CPU with the highest maximum frequency (a performance core on a hybrid part); on ties the
/// lowest-numbered one.
fn pick_cpu(freqs: &[(usize, u64)]) -> Option<usize> {
    freqs
        .iter()
        .max_by_key(|&&(cpu, freq)| (freq, Reverse(cpu)))
        .map(|&(cpu, _)| cpu)
}

fn read_cpu_freqs() -> Vec<(usize, u64)> {
    let Ok(entries) = fs::read_dir("/sys/devices/system/cpu") else {
        return Vec::new();
    };
    entries
        .filter_map(Result::ok)
        .filter_map(|entry| {
            let name = entry.file_name().into_string().ok()?;
            let cpu: usize = name.strip_prefix("cpu")?.parse().ok()?;
            let freq = fs::read_to_string(entry.path().join("cpufreq/cpuinfo_max_freq")).ok()?;
            Some((cpu, freq.trim().parse().ok()?))
        })
        .collect()
}

fn run_cell(rlb: &Path, cpu: usize, pin: bool, cell: &Cell, options: &Options) -> Measurement {
    let mut command = if pin {
        let mut command = Command::new("taskset");
        command.arg("-c").arg(cpu.to_string()).arg(rlb);
        command
    } else {
        Command::new(rlb)
    };
    command
        .args([
            "run",
            "--workload",
            &cell.workload,
            "--variant",
            &cell.variant,
        ])
        .args(["--n", &(1usize << cell.exponent).to_string()])
        .args([
            "--reps",
            &options.reps.to_string(),
            "--seed",
            &options.seed.to_string(),
        ])
        .args(["--budget-secs", &options.budget_secs.to_string()]);
    match command.output() {
        Ok(output) if output.status.success() => {
            let stdout = String::from_utf8_lossy(&output.stdout);
            match stdout.lines().find(|line| !line.trim().is_empty()) {
                Some(line) => Measurement::from_json(line)
                    .unwrap_or_else(|e| failed(cell, format!("unparseable output: {e}"))),
                None => failed(cell, "rlb printed nothing".to_owned()),
            }
        }
        Ok(output) => failed(
            cell,
            String::from_utf8_lossy(&output.stderr).trim().to_owned(),
        ),
        Err(e) => failed(cell, format!("cannot start rlb: {e}")),
    }
}

fn read_results(path: &Path) -> Result<Vec<Measurement>, String> {
    let text =
        fs::read_to_string(path).map_err(|e| format!("cannot read {}: {e}", path.display()))?;
    let mut measurements = Vec::new();
    for (index, line) in text
        .lines()
        .enumerate()
        .filter(|(_, line)| !line.trim().is_empty())
    {
        match Measurement::from_json(line) {
            Ok(m) => measurements.push(m),
            Err(e) => eprintln!(
                "sweep: {}:{}: skipping unparsable line: {e}",
                path.display(),
                index + 1
            ),
        }
    }
    Ok(measurements)
}

fn write_report(options: &Options, cpu: usize) -> Result<(), String> {
    let measurements = read_results(&options.out)?;
    let text = report::render(&measurements, &MachineInfo::collect(cpu));
    if let Some(parent) = options.md.parent().filter(|p| !p.as_os_str().is_empty()) {
        fs::create_dir_all(parent)
            .map_err(|e| format!("cannot create {}: {e}", parent.display()))?;
    }
    fs::write(&options.md, text)
        .map_err(|e| format!("cannot write {}: {e}", options.md.display()))?;
    eprintln!("sweep: wrote {}", options.md.display());
    Ok(())
}

fn run(args: &[String]) -> Result<(), String> {
    let options = parse_options(args)?;
    let cpu = options.cpu.unwrap_or_else(|| {
        pick_cpu(&read_cpu_freqs()).unwrap_or_else(|| {
            eprintln!("sweep: warning: cannot read cpuinfo_max_freq; using cpu0");
            0
        })
    });
    if options.report_only {
        return write_report(&options, cpu);
    }

    let infos: Vec<WorkloadInfo> = registry::all()
        .iter()
        .map(|w| WorkloadInfo {
            name: w.name().to_owned(),
            max_n: w.max_n(),
            footprint_per_n: w.footprint_per_n(),
            variants: w.variants().iter().map(|v| (*v).to_owned()).collect(),
        })
        .collect();
    let (mut cells, skips) = plan_cells(&infos, &options, mem_available_kib());
    shuffle_cells(&mut cells, options.seed);

    if options.dry_run {
        println!("cpu: {cpu}");
        for cell in &cells {
            println!(
                "run  {} {} 2^{}",
                cell.workload, cell.variant, cell.exponent
            );
        }
        for skip in &skips {
            println!(
                "skip {} {} n={}: {}",
                skip.workload, skip.variant, skip.n, skip.note
            );
        }
        return Ok(());
    }

    let rlb = locate_rlb()?;
    let pin = taskset_available();
    if !pin {
        eprintln!("sweep: warning: `taskset` not found; running unpinned");
    }
    if let Some(parent) = options.out.parent().filter(|p| !p.as_os_str().is_empty()) {
        fs::create_dir_all(parent)
            .map_err(|e| format!("cannot create {}: {e}", parent.display()))?;
    }
    let mut results = OpenOptions::new()
        .create(true)
        .append(true)
        .open(&options.out)
        .map_err(|e| format!("cannot open {}: {e}", options.out.display()))?;
    let mut record = |m: &Measurement| -> Result<(), String> {
        writeln!(results, "{}", m.to_json())
            .and_then(|()| results.flush())
            .map_err(|e| format!("cannot write {}: {e}", options.out.display()))
    };
    for skip in &skips {
        record(skip)?;
    }
    for (index, cell) in cells.iter().enumerate() {
        eprint!(
            "sweep: [{}/{}] {} {} 2^{} ... ",
            index + 1,
            cells.len(),
            cell.workload,
            cell.variant,
            cell.exponent
        );
        let measurement = run_cell(&rlb, cpu, pin, cell, &options);
        eprintln!("{}", measurement.status);
        record(&measurement)?;
    }
    write_report(&options, cpu)
}

fn main() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    match run(&args) {
        Ok(()) => ExitCode::SUCCESS,
        Err(message) => {
            eprintln!("sweep: {message}");
            ExitCode::from(2)
        }
    }
}

````rust
//! Blob workloads: `blob-load` and `blob-lookup`.
//!
//! Both use the `bst-bulk` tree stored in a rustlink `Arena` and frozen into a blob.
//!
//! * `blob-load`: build time is rebuilding the arena from the plan (what a program without a
//!   blob has to do at start-up); the traverse metric is `BlobRef::verify` over the frozen image,
//!   in ns per node.
//! * `blob-lookup`: the traverse metric is random lookups through the *verified blob view*, to
//!   compare with `bst-bulk` lookups through the arena.

use rustlink::{Arena, BlobRef, Link, Links, Region, Width, impl_links};
use zerocopy::byteorder::little_endian::U32;
use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};

use crate::plan::{Plan, Spec};
use crate::rng::Rng;
use crate::workload::{Limit, Outcome, Reach, Workload};

/// The workloads this module provides.
pub fn workloads() -> Vec<Box<dyn Workload>> {
    vec![Box::new(BlobLoad), Box::new(BlobLookup)]
}

const VARIANTS: &[&str] = &["abs32", "abs16", "rel32", "rel16", "rel8"];

/// A node type that can be frozen into a blob and searched as a BST.
trait BlobNode:
    Copy + FromBytes + IntoBytes + Immutable + KnownLayout + Unaligned + Links + 'static
{
    type Child: Link<Self>;
    const LIMIT: Limit;
    fn from_spec(owner: usize, spec: Spec) -> Self;
    fn payload(&self) -> u32;
    fn a(&self) -> Self::Child;
    fn b(&self) -> Self::Child;
}

macro_rules! blob_node {
    (
        $node:ident, $link:ident, $w:ty, $schema:expr, $limit:expr,
        |$owner:ident, $child:ident| $make:expr
    ) => {
        #[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned, Clone, Copy)]
        #[repr(C)]
        struct $node {
            payload: U32,
            a: $link<$node, $w>,
            b: $link<$node, $w>,
        }

        impl_links!($node, schema = $schema, links = [a, b]);

        impl BlobNode for $node {
            type Child = $link<$node, $w>;
            const LIMIT: Limit = $limit;

            fn from_spec(owner: usize, spec: Spec) -> Self {
                let link = |$owner: usize, $child: Option<u32>| {
                    let $child = $child.map(|c| c as usize);
                    $make.expect("reach checked by the workload")
                };
                $node {
                    payload: U32::new(spec.payload),
                    a: link(owner, spec.a),
                    b: link(owner, spec.b),
                }
            }

            fn payload(&self) -> u32 {
                self.payload.get()
            }

            fn a(&self) -> Self::Child {
                self.a
            }

            fn b(&self) -> Self::Child {
                self.b
            }
        }
    };
}

);

    },

);
blob_node!(
    Rel16,
    OptRel,

    },

fn rebuild<N: BlobNode>(plan: &Plan) -> Arena<N> {
    let mut arena = Arena::with_capacity(plan.nodes.len());
    for (owner, spec) in plan.nodes.iter().enumerate() {
        arena.push(N::from_spec(owner, *spec));
    }
    arena
}

fn contains<N: BlobNode, R: Region<N>>(region: &R, root: usize, key: u32) -> bool {
    let Some(mut cursor) = region.cursor(root) else {
        return false;
    };
    loop {
        let node = cursor.get();
        let payload = node.payload();
        if key == payload {
            return true;
        }
        let child = if key < payload { node.a() } else { node.b() };
        match cursor.follow(child) {
            Some(next) => cursor = next,
            None => return false,
        }
    }
}

fn lookups<N: BlobNode, R: Region<N>>(region: &R, root: usize, probes: &[u32]) -> Pass {
    let hits = probes
        .iter()
        .filter(|&&key| contains(region, root, key))
        .count() as u64;
    Pass {
        checksum: hits,
        units: probes.len() as u64,
    }
}

fn inputs(params: &Params) -> (Plan, Reach, Vec<u32>) {
    let n = params.n;
    let plan = Plan::balanced_bst(n);
    let reach = plan.reach();
    let mut rng = Rng::new(params.seed);
    let probes = (0..n).map(|_| rng.below(2 * n as u64) as u32).collect();
    (plan, reach, probes)
}

fn run_load<N: BlobNode>(params: &Params, plan: &Plan, reach: &Reach) -> Result<Outcome, String> {
    if !N::LIMIT.admits(plan.nodes.len(), reach) {
        return Ok(Outcome::Unreachable(*reach));
    }
    let image = rebuild::<N>(plan).freeze();
    let nodes = plan.nodes.len() as u64;
    Ok(Outcome::from_reps(
        run_reps(
            params,
            nodes,
            || rebuild::<N>(plan),
            |_| {
                let view = BlobRef::<N>::verify(&image).expect("a frozen image verifies");
                Pass {
                    checksum: view.len() as u64,
                    units: nodes,
                }
            },
        ),
        size_of::<N>(),
        "node",
        Some(*reach),
    ))
}

fn run_lookup<N: BlobNode>(
    params: &Params,
    plan: &Plan,
    reach: &Reach,
    probes: &[u32],
) -> Result<Outcome, String> {
    if !N::LIMIT.admits(plan.nodes.len(), reach) {
        return Ok(Outcome::Unreachable(*reach));
    }
    // Verification happens once, outside the timed region; the view borrows the local image.
    let image = rebuild::<N>(plan).freeze();
    let view = BlobRef::<N>::verify(&image).expect("a frozen image verifies");
    let root = plan.root().unwrap_or(0);
    Ok(Outcome::from_reps(
        run_reps(
            params,
            plan.nodes.len() as u64,
            || rebuild::<N>(plan),
            |_| lookups(&view, root, probes),
        ),
        size_of::<N>(),
        "lookup",
        Some(*reach),
    ))
}
````

````markdown
# rustlink

Narrow typed links for Rust: 1-, 2-, 4- or 8-byte offsets that replace 8-byte pointers inside
pointer-dense data structures. It adapts the "links narrower than pointers" mechanism of the
[Goose language](https://github.com/aardappel/goose) to Rust and ships with a benchmark suite that
measures where narrow links pay.

## What it provides

* Four link types, all `Copy`, 1-byte aligned and stored little-endian:
  * `Abs` / `OptAbs`: an element index. The width bounds the *region size*.
  * `Rel` / `OptRel`: a signed element delta from the element that stores the link. The width
    bounds the *link distance*, so a region can be arbitrarily large when links are local.
  * `Opt*` forms reserve a value for null. Every width (`u8`, `u16`, `u32`, `u64`) works with
    every form.
* `Region`: bounds-checked resolution. A link applied to the wrong region, a corrupted link or a
  dangling link yields `None` or `Err`, never undefined behavior.
* `Arena<T>`: an append-only array whose indices never change, so links inside it never dangle.
* A frozen, position-independent blob: `Arena::freeze` writes a header plus the raw elements, and
  `BlobRef::verify` checks the header, the exact length, the element size, a schema id and every
  link before returning a zero-copy view.
* No `unsafe` code, `#![no_std]` with `alloc`, no feature flags.

## Reach

Links count elements of `T`, not bytes.

| Width | `Abs`: elements addressable | `Rel`: delta range |
|---|---|---|
| `u8` | 256 | -128 to 127 |
| `u16` | 65,536 | -32,768 to 32,767 |
| `u32` | 4,294,967,296 | -2^31 to 2^31 - 1 |
| `u64` | 2^64 | -2^63 to 2^63 - 1 |

`OptAbs` addresses one element fewer than `Abs` of the same width. `OptRel` cannot point an element
at itself (delta 0 is null).

## Example

```rust
use rustlink::{Arena, BlobRef, OptAbs, Region, impl_links};
use zerocopy::byteorder::little_endian::U32;
use zerocopy::{FromBytes, Immutable, IntoBytes, KnownLayout, Unaligned};

// A tree node: a key and two optional links of 2 bytes each. The node is 8 bytes; the same node
// with two 8-byte pointers is 24.
#[derive(FromBytes, IntoBytes, Immutable, KnownLayout, Unaligned, Clone, Copy)]
#[repr(C)]
struct Node {
    key: U32,
    left: OptAbs<Node, u16>,
    right: OptAbs<Node, u16>,
}
impl_links!(Node, schema = 0x4558_414D_0001, links = [left, right]);

let mut arena = Arena::new();
let leaf = arena.push(Node { key: U32::new(1), left: OptAbs::NULL, right: OptAbs::NULL });
arena.push(Node { key: U32::new(2), left: OptAbs::new(Some(leaf))?, right: OptAbs::NULL });
assert_eq!(size_of::<Node>(), 8);

// Links are resolved against the arena with a bounds check.
let root = arena.cursor(1).unwrap();
let left = root.follow(root.get().left).unwrap();
assert_eq!(left.get().key.get(), 1);

// A frozen image holds no addresses. Verify it when loading it back.
let image = arena.freeze();
let view = BlobRef::<Node>::verify(&image)?;
assert_eq!(view.len(), 2);
# Ok::<(), Box<dyn std::error::Error>>(())
```

scalar fields. Links into another region are not range-checked by `verify`; they stay
bounds-checked whenever they are followed.
````
